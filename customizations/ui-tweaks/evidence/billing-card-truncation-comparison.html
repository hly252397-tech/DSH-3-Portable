问题分析

位置：sidebar.footer.action 插槽
原因：卡片容器宽度不足时，右侧内容（可能是图标或装饰元素）被隐藏

修复方案

方案 A（推荐）：修改插件 CSS
文件：Data/DSH/profiles/web/node_modules/@kenz1117/dsh-ui-usage-billing/lib/client.js
改动：将 .VWh0dG_trigger 的 overflow: hidden 改为 overflow: visible
