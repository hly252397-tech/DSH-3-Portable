# dsh-black-hole

DSH 内置黑洞内容板块的本地插件实现。

## 当前能力

- 创建多个用户自定义黑洞；
- 手动保存对话成果和文本资料；
- 自动生成标题、摘要、类型和标签；
- 资料去重、状态、来源和版本化记录；
- 黑洞内搜索和跨黑洞关联召回；
- DSH 对话输入区保存入口；
- 发现当前对话与黑洞已有内容相关时提示用户；
- 黑洞成长值、等级和开发手册；
- 智力配置预留（禁用并说明未接入）；提醒强度设置可用。

当前“理解”采用本地确定性整理和检索，不修改基础模型权重；后续可接入 DSH 的模型路由做更深层归纳。

本版是可运行的文本记忆模块，不是完整超级大脑。独立模型调用、向量检索、知识中心双向联通、PDF/Office/OCR 和自然语言自动存入尚未实现。

入口：DSH 输入区的“黑洞空间”，或右侧卡片的 + → 黑洞。“放进黑洞”会提取当前已加载的最近可见对话，保存前可编辑；不提取思考过程、工具结果、图片或完整会话历史。引用追加到当前输入框，不覆盖已有草稿，也不自动发送。

提醒仅检查当前会话；带会话来源的黑洞只向关联会话提醒，无会话来源的黑洞视为共享参考。此规则是单用户界面过滤，不是多租户权限隔离。

限制：UTF-8 文本单份 ≤1 MiB，最多 64 个黑洞、每洞 4000 份资料、总库序列化后 ≤12 MiB；超限拒绝写入，不截掉旧资料。成长为知识积累游戏分数，从 0 开始，不代表模型真实智商。

开发手册与验收结果：仓库 docs/01-当前工作/I026-黑洞空间/01-实机落地.md。

## 数据位置

默认保存到 `DSH_HOME/workbench/black-hole/black-holes.json`，不写入应用安装目录。
