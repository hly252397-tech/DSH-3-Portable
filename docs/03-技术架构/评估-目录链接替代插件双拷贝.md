# 评估：目录链接替代「local/ 与 node_modules 双拷贝」

状态：**评估完成，方案可行（pnpm `link:` 协议）；未采纳实施**
评估日期：2026-09-11（Asia/Shanghai）
来源：官方桌面 `runtime-tree.ts`「Host-owned package available to external plugins through a directory link」（2026-09-11 审阅，见 [官方兼容基线](DeepSeek-Harness-官方兼容基线.md) 2026-09-11 节）

## 痛点与根因

AGENTS.md 记载：`Data/DSH/profiles/web/local/<插件>` 与 `node_modules/<插件>` 是两份拷贝，改前者必须同步后者（宿主读后者），src 文件与 cordis.patch.yml 都要动。实测根因：本地插件在 profile `package.json` 中以 `file:` 协议声明（现存三种写法：`file:G:/绝对路径`、`file:local\…`、`file:./local/…`），pnpm 对 `file:` 依赖**物化为真实目录拷贝**进 node_modules（实测 `LinkType` 为空），因此 local 源的修改不会传播。

## 沙箱实验结论（pnpm 11.24 + nodeLinker: hoisted + 独立 workspace，2026-09-11）

| 验证项 | 结果 |
|---|---|
| `link:./local/<pkg>` 声明 → `pnpm install` | ✅ pnpm 在 node_modules 创建 **Junction**（`node_modules/dsh-demo → local/dsh-demo`），无需手动 mklink、无需特权 |
| Node 模块解析穿透 junction | ✅ `require()` 正常 |
| 实时传播 | ✅ 修改 `local/dsh-demo/index.js` 后**零操作**立即读到新值（"final-live-check"） |
| 重装存活 | ✅ package.json 变更后 `pnpm install --no-frozen-lockfile` 重建，两个 link 插件 junction 均在、内容保持 |
| 与新增依赖共存 | ✅ 追加第二个 `link:` 依赖正常解析安装（"1 dependencies were added"） |

附带发现（非新风险）：pnpm CI 模式的 frozen-lockfile 陷阱在本场景同样存在（package.json 变更后须 `--no-frozen-lockfile`），与 `Build-DSH-Portable.ps1` 注释记载一致。

关键前提：沙箱必须有自己的 `pnpm-workspace.yaml`（`packages: [.]`）隔离仓库根 workspace——真实 Profile 已具备此文件。

## 采纳方案（待实施）

1. profile `package.json` 中 5 个本地插件（dsh-better-sidebar、dsh-restart-button、dsh-sidebar-spaces、dsh-work-mode；dsh-codex-ui 为 npm 依赖不涉及）的 `file:…` 声明统一改为 `link:./local/<pkg>`（顺带消除三种写法并存）。
2. 删除 node_modules 下对应真实目录拷贝，执行一次 `pnpm install --no-frozen-lockfile` 让 pnpm 建立 junction。
3. 走完整门禁：tsc + 全量测试 + Build + A/B 部署 + 重启后真实 Profile 验证全部本地插件加载。
4. 验收重点（实施前必须逐项过）：`profile-quarantine`（移动 node_modules 目录时移动的是链接本身）、`profile-repair`、`plugin-seed`/`desktop-host` 的 pnpm add 流程对既有 link 依赖的处置（沙箱已验证 link+link 共存，registry 包并行安装未实测，需在真实 Profile 首次验证覆盖）、bundle 层 patch 条目按包名解析不受影响。

## 与官方技术的差异

官方 `runtime-tree.ts` 是宿主自有包经目录链接暴露给插件（避免按 Profile 安装），解决的是"宿主包分发"；本仓库痛点是"本地源码插件的双拷贝"，用 pnpm 原生 `link:` 协议即可解决，不需要移植官方实现。

## 语义变化（采纳后）

- `node_modules/<本地插件>` 不再是独立拷贝：直接改 node_modules 内文件 = 改 local 源（更正确的心智模型）。
- AGENTS.md 双拷贝规则作废，替换为"改 local/ 即时生效，无需同步"。
