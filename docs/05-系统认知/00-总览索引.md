## 🏠 独立家园代际隔离（官方兼容基线所称「数据安全核心」）

2026-09-30 补充：schema 2 家园绑定源码已支持直接引用 `Data/Runtime/Harness/slots`，不再复制整个运行时；冷启动未提交事务须严格选择并校验 previous 槽/家园。当前生产仍为 schema 1，未迁移。因官方暂无覆盖 MCP/IM/定时任务的全局入站拒绝机制，新内核正式激活已在本轮候选源码中失败关闭；无业务 shadow 通过不能代替完整 Profile 验收。实际状态与门禁见 [本轮记录](../01-当前工作/20260930-构建独立更新与定制保护.md)。

便携版为**每个 DSH 运行时版本绑定一个代号代际**，其用户数据落在 `Data/DSH-generations/<代>/home`：

- 当前代 `v4-rc2b`，声明在 `Data/Updates/Harness/homes/0.1.7-rc.2.json`（`{runtimeVersion, generation}`），数据目录 `Data/DSH-generations/v4-rc2b/home`；
- **旧版继续读冻结的 `Data/DSH`**（`Data/DSH-generations/v4-rc2-old1` 是上一代遗留），两代互不污染；
- 绑定**损坏时 fail-closed**：宁可不启动，也不把数据写进错误代际；
- 因此"用户数据在 `%USERPROFILE%\.dsh`"这类旧表述**只描述上游形态，不描述便携版**。

改动家园绑定、代际目录或 `portable-paths` 解析时，必须同步本索引与 `02-当前状态.md` 的对应行。
