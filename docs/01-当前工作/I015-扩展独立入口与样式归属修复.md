## 热更新样式根因与修复

实际运行时 `@deepseek-ai/dsh-client-modules/lib/client.js` 的 `claimStyles` 把未标记的 `style:not([data-plugin])` 归属到当时加载的插件。社区插件 `@michengai/dsh-codex-ui@0.2.101` 的 React 样式没有标记，被其他插件误认领，随后热更新清理时被移除。

在保留的本地副本和实际安装副本中，为 8 个 React style 节点及 2 个 head 动态样式加入 `data-plugin="@michengai/dsh-codex-ui"`，不改 CSS 内容或官方运行时。测试提取当前实际 loader 的函数，复现误归属并验证保护。修复后再次热更新本插件，侧栏样式仍保留。

同时修复页面定位：槽包装元素尺寸为零，不能当边界；改测量可见侧栏并用 ResizeObserver 跟随。

升级边界：这是当前社区插件 0.2.101 的本地补丁，不是已发布的上游修复。未来升级可能覆盖，届时应核对新版并重测，不可盲目覆盖不同版本。测试包含本地与安装副本一致性检查。未改 Profile 依赖来激活第二份插件。
