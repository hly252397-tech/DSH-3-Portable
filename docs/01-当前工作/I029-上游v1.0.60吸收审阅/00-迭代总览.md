## 2. 审阅方法（含一处运维经验）

1. 上游源码抓取：`git fetch upstream main "+refs/tags/*:refs/upstream-tags/*" --no-tags`。
   **放进独立命名空间 `refs/upstream-tags/*`**，避免 `git fetch upstream --tags` 与便携仓库自有 `v1.0.x` 标签冲突（D-16）。
   ⚠️ 本机 git 直连 github 曾报 `schannel: AcquireCredentialsHandle failed` / `Failed to connect to port 443`；
   加 `-c http.sslBackend=openssl -c http.version=HTTP/1.1` 后可正常抓取（浏览器通道始终可用）。
2. 官方双基线门禁：`App/resources/node/node.exe scripts/verify-dsh-official-baseline.mjs --online` → **PASS**
   （`bundled=0.1.2-rc.1 upstream=0.1.5-rc.2@c291e796… online=verified`）。
3. **逐文件读 diff**（9 个 `src/` + `scripts/prepare-runtime.ts` 全文读），再对每处候选改动核对本仓库的**契约**是否已有——
   不是核对符号名（见 §0 教训）。
