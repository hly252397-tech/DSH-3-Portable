# I024：实施记录

实施步骤按时间顺序记录。每步说明目的、关键文件与产物（门禁输出 / 候选 ID）。

## 步骤 1：基线核对

```sh
./App/resources/node/node.exe scripts/verify-dsh-official-baseline.mjs --online
```

输出：`[official-spec] 官方 HEAD 已变化：基线 c389f96bf3a9b6807cb71ed6bdad5849be0df6d8，当前 5dda764ed3aa172535a7967b06ff95d9cbfe536a。先人工审阅官方规范并更新基线。`

**结论**：本功能走 Electron 外壳 IPC（`clipboard.writeText`、`BrowserWindow`、`ipcMain.handle`），不调用任何 DSH 插件 API；官方 HEAD 变化对实现无直接影响。但需在 `docs/03-技术架构/DeepSeek-Harness-官方兼容基线.md` 留位"基线待人工审阅"。

## 步骤 5：主进程接入

**文件**：`src/main.ts`

变更：
1. `import { ..., clipboard, ... }` from electron；`import { FEATURE_PANEL_CATEGORIES, FEATURE_PANELS } from './feature-panels.js'`；`import { ..., mayInvokeFeaturePanelsCopy, ... }` from shell-ipc-policy
2. `let featurePanelsWindow: BrowserWindow | undefined` 模块变量
3. `resolveShellAsset` 字面量联合加 `'feature-panels.html'`
4. `shellBootstrap` 返回 `featurePanels: { categories, panels }`，并把 `localizedShellActions` 调用的第三参数改为 `!app.isPackaged`
5. `broadcastShellBootstrap` / `broadcastShellState` / `applyDesktopTheme` / `installShortcutHandler` 的窗口列表加 `featurePanelsWindow`
6. `shellRendererKind` 加 `if (sender === featurePanelsWindow?.webContents) return 'feature-panels'`
7. `isActionEnabled` 加 `if (id === 'feature-panels') return !app.isPackaged` 守门
8. `executeShellAction` 加 `else if (id === 'feature-panels') { showFeaturePanelsWindow(); return }`
9. 新增 `showFeaturePanelsWindow()`：760×640、`parent: mainWindow, modal: true, sandbox: true`、加载 `feature-panels.html`；`featurePanelsWindow` 模块级缓存 + `closed` 清理
10. `installShellIpc` 加 `featurePanelsCopy` IPC：`mayInvokeFeaturePanelsCopy` 守门 → 校验 string → `clipboard.writeText` → return true
