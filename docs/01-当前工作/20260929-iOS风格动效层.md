# 2026-09-29 — iOS 风格动效层（用户要求「iOS 27 的效果」）

## 需求与定位

用户在界面切换排查后追加：「动画效果可以再优化吗？我希望有 iOS 27 的效果」——给界面切换加 Apple 风格动效。落在 **ui-tweaks 客户端 bundle**（可变层，热重载即生效，不动不可变槽）。

## 实现（`customizations/ui-tweaks/lib/client.js`）

- **曲线令牌**：`--dsh-ease-ios: cubic-bezier(.32,.72,0,1)`（Apple sheet 减速曲线）+ `--dsh-ease-ios-spring`（15% 过冲弹簧）；时长 420ms 视图 / 260ms 元素 / 160ms 悬停。
- **视图切换入场**（核心）：观察 `#root` 与 `.dcu-settings-page` 的**顶层子节点替换**（childList、去抖 240ms、同一元素不重放），对主内容（`.pI_x6G_frame` 或非导航最大直接子节点）加 `dsh-ios-view` —— 淡入 + 上移 12px + 缩放 .986→1。流式消息在深层子树，不会误触发。
- **弹层浮现**：body 直挂 portal（dialog/menu/dcu-modal/popper）新增时 `dsh-ios-pop` 弹簧缩放浮现。
- **侧栏微过渡**：导航按钮/会话树/设置导航的 hover 与选中态平滑过渡；选中项轻弹簧缩放。
- **退出开关**：系统「减少动态」（prefers-reduced-motion）自动整层退出；手动删 `<html>` 的 `data-dsh-motion="ios"` 同效（CSS 以该属性为总闸）。
- **沙箱防御**：matchMedia/querySelector/observer 回调全部 fail-soft（首轮全量 4 红 → 修复后全绿），装饰层任何异常不外溢、不影响既有搬家/工具条逻辑。

### 起因与现状事实

设置导航 19 个入口被官方（codex-ui）只分成「个人 / 集成」两组，十几项全堆在「集成」里。
真实结构（0.2.0-rc.1 + codex-ui 1.1.18，取自 `lib/client.js` 设置导航渲染段）：

```
nav.dcu-settings-nav
├─ button.dcu-settings-back            返回应用
├─ label.dcu-settings-search > input   搜索
└─ div.dcu-settings-groups             ← 官方分组容器
```

绝不移动/改写 React 节点：原 nav 打 `dsh-grouped` 标记并用 CSS 隐藏官方分组容器，紧随其后渲染镜像盒

`click()`；800ms 轮询同步激活态（`aria-current`/`data-active`/`.active`/`data-state="active"`）、搜索过滤可见性，
并把「一项都不剩」的组连标题一起收起。撤掉 `dsh-grouped` 标记即完全还原。

六组分类：基础（常规/模型/桌面设置）· 插件与扩展（插件市场/内置插件/插件配置/技能/连接器）·

## 第五轮：对照 `emilkowalski/apple-design` 的三条低风险修正（2026-09-29）

**起因**：用户问「apple-design 模块这是什么」→ 核实为 Emil Kowalski（Vercel / Linear，animations.dev 作者）
整理的 17 条 Apple 设计原则（主要出自 WWDC 2018 *Designing Fluid Interfaces* 与 WWDC 2020 *The Details of
UI Typography*），经 `ui-skills.com` 注册表（`ibelick/ui-skills` 仓库）分发。排除两个同名误认：空仓库
`HenryDu8133/dsh-apple-design-theme`、无关的 npm `apple-design`（Vue3 组件库）。

**可用性判断（三档）**：

| 档 | 条数 | 说明 |
|---|---|---|
| 结构上不可用 | 6 | 手势 / 拖拽类。ui-tweaks 是纯装饰层，铁律是「只加 class 触发 CSS，不改布局、不拦事件、不动 React 状态」 |
| 部分可用 | ~1.5 | 需要改 JS 语义或布局的 |
| 低风险可用 | 3 | 第 15 条字排、第 1 条即时反馈、第 14 条减弱动效 |

用户回「你看着来」授权后按风险排序实施：纯 CSS 的排版 → CSS 的按下反馈 → 最后动 JS 语义的降档。

### 改动

1. **第 15 条（字排，WWDC 2020）** —— 分组标题原写法 `text-transform:uppercase` + `letter-spacing:.04em`
   是典型网页风。Apple 侧栏分组标题靠「更小 + 更低对比 + 靠留白分层」，不靠字距撑层级；且 `.04em` 加在
   11px 中文上会显松散。改为：去 uppercase、字距收到 `.01em`、`padding-top` 由 10px 提到 12px。
2. **第 1 条（即时反馈）** —— 镜像项补 `:active`：pointer-down 那一瞬给 `scale(.985)` +
   `transition:transform 100ms ease-out`。**只加在自绘镜像上**——官方导航自带 animation，
   叠 transform 会和 `dsh-ios-select` 抢合成优先级。
3. **第 14 条（减弱动效）** —— 语义变更，**最重要的一条**。原行为：系统开「减少动态」时整层
   `data-dsh-motion` 被 `delete` ⇒ 所有元素彻底零反馈，切换像卡住。第 14 条与 WCAG 口径一致：
   reduced ≠ 没有反馈，而是换成不引发前庭反应的等价物。改为**降档**：总闸取三态
   `ios`（全量）/ `reduced`（只剩 180ms 纯 opacity 交叉淡化）/ 属性被删（整层静止），
   并把 `html[data-dsh-motion="reduced"]` 的计费面板接管补齐（原来只认 `ios` 档，
   否则面板自带的位移入场会在降档里漏出来）。

### 自验（真实桌面实例，CDP 读真实 DOM 与 computed style）

- **排版**：`#dsh-settings-groups .dsh-sg-title` → `text-transform:none`、`letter-spacing:0.11px`
  （= .01em × 11px）、`padding-top:12px`、`font-size:11px`；运行期样式表里已无 `text-transform`。
- **按下反馈**（真实 `Input.dispatchMouseEvent` 按住不放，分点采样）：
  按下 +4ms `:active` 即命中（transform 仍在起点）→ +122ms `matrix(0.985,0,0,0.985,0,0)`、
  实测宽 254→250.19px → 松手复原 254。即反馈落在 pointer-down 当瞬、100ms 内收敛，符合第 1 条。
  （首轮按 y=70 采样全为 `active:false`，原因是镜像盒 800ms 轮询重排后项位从 y=70 移到 y=160、
  采样点已落在组标题上——**先 hit-test 再采样**，别信缓存坐标。）
- **降档**：`Emulation.setEmulatedMedia prefers-reduced-motion:reduce` →
  `matchMedia` 命中、`syncFlag` 在 900ms 内把总闸 `"ios"`→`"reduced"`；
  同一元素 `.dcu-settings-main.dsh-ios-view` 的 animation 由 `dsh-ios-view-in 0.42s
  cubic-bezier(0.32,0.72,0,1)` 变为 `dsh-ios-fade-in 0.18s ease-out`（纯透明度，无位移/缩放）。
- **降档下的计费面板接管**：降档中打开使用统计面板 → `.dsh-billing-modal` 拿到 `dsh-ios-pop` 类但
  computed `animation:none / 0s`，页签 `animation:none` ⇒ 单次过渡，无双弹回归。
- CDP 连接断开后模拟媒体自动复原，总闸随之回到 `"ios"` —— 顺带证明 `change` 监听**双向**可用。

### 门禁

### 三个坑（都真实踩过）

1. **`data-dsh-nav-key` 是去空白的**。`navKey(s) = String(s||'').replace(/\s+/g,'')`，
   镜像按钮的 `data-dsh-nav-key` 存的是这个结果。选择器写 `Agent 预设`（带空格）就**一条都匹配不上**。
   首次真实 DOM 验证直接抓到 `noIcon: ["Agent预设","DSH手册","CodexUI","IM助理"]`、`distinctIcons: 16`。
   修法两条：生成器补 `navKey()`；测试的 `navMembers()` 改成按 navKey 形态比对，让这类错以后被拦住。
2. **选择器特异性**。既有规则是 `.dsh-settings-groups .dsh-sg-item{...}`（两段），
   新规则若只写 `.dsh-sg-item`，按「后层按选择器胜出」会把 `padding`/`color` 压回去。生成器统一带全前缀。
3. **data URI 里的单引号**。本层 CSS 是字符串数组，生成行要包进单引号 JS 字符串，
   `stroke='black'` 的单引号必须编码成 `%27`（`<`→`%3C`、`>`→`%3E`、`#`→`%23` 同理）。
