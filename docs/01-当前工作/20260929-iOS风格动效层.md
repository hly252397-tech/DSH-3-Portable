## 需求与定位

## 实现（`customizations/ui-tweaks/lib/client.js`）

- **曲线令牌**：`--dsh-ease-ios: cubic-bezier(.32,.72,0,1)`（Apple sheet 减速曲线）+ `--dsh-ease-ios-spring`（15% 过冲弹簧）；时长 420ms 视图 / 260ms 元素 / 160ms 悬停。
- **视图切换入场**（核心）：观察 `#root` 与 `.dcu-settings-page` 的**顶层子节点替换**（childList、去抖 240ms、同一元素不重放），对主内容（`.pI_x6G_frame` 或非导航最大直接子节点）加 `dsh-ios-view` —— 淡入 + 上移 12px + 缩放 .986→1。流式消息在深层子树，不会误触发。
- **弹层浮现**：body 直挂 portal（dialog/menu/dcu-modal/popper）新增时 `dsh-ios-pop` 弹簧缩放浮现。
- **侧栏微过渡**：导航按钮/会话树/设置导航的 hover 与选中态平滑过渡；选中项轻弹簧缩放。
- **退出开关**：系统「减少动态」（prefers-reduced-motion）自动整层退出；手动删 `<html>` 的 `data-dsh-motion="ios"` 同效（CSS 以该属性为总闸）。
- **沙箱防御**：matchMedia/querySelector/observer 回调全部 fail-soft（首轮全量 4 红 → 修复后全绿），装饰层任何异常不外溢、不影响既有搬家/工具条逻辑。

## 修复：「设置页弹两下」（用户实证反馈，2026-09-29 深夜）

- **根因**：触发路径叠车——点击布防路径闪完动画后把 lastFlashed 重置为 null，第二观察器（watchViewRoot）对同一目标再次放行，同一次切换连闪两遍（设置页段切换最易复现：内容分批挂载）。
- **修法（结构根除）**：①删除 watchViewRoot 双观察器（连拍早已证明其对 React 深层换页无效，只会叠车）；②flash() 增加 **450ms 全局冷却**，视图入场与弹层浮现所有路径共用一处节流——第二次闪在代码路径上不再可能。
- **验证**：node --check + 定向测试全绿 + 全量 0 fail；四副本同步热重载即时生效。动画单次过渡的连拍实证见上节（13514B 起始帧序列）。本段复现连拍因用户实时操作与窗口移动竞速未能再次采样，以结构根除+测试为凭。

## 修复二：「左下角计费区域弹两下」（用户指认点击目标后定位）

- **真凶不是我的动效层**：计费用量面板来自社区插件 @kenz1117/dsh-ui-usage-billing，其弹层根 .VWh0dG_dashboardModal 无 role/radix 标记，我的 pop 观察器（dialog/menu/dcu-modal/radix）根本匹配不到。双弹=插件**自带两段链式入场**（VWh0dG_dashboardIn 面板 0.16s + VWh0dG_tabPanelIn 页签）。
- **接管修法**：动效层内 ①压掉插件两段自带入场（animation:none，仅在 data-dsh-motion=ios 生效）②把 .VWh0dG_dashboardModal 纳入 pop 观察器——由统一弹簧播**唯一一次**。
- **失效边界**：VWh0dG_ 前缀是插件构建产物，该插件升级后类名改变、接管静默失效（双弹回归即此因）；届时重取类名更新选择器即可。
- **验证**：类名取自该插件 lib/client.js 的真实 css-module 映射（非猜测）；node --check + 定向 + 全量 0 fail；四副本同步。用户复测口径：点开计费卡应只见一次弹簧入场。
