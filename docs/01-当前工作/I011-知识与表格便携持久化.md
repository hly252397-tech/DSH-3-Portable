# 知识库与数据库便携持久化

日期：2026-09-05，接续 I009 / I010 的 P0。

## 本轮边界

修复 sidebar-spaces 知识库与表格依赖 localStorage origin 的问题；这不是“所有任务丢失问题已解决”的声明。原会话日志、自动化任务、工作区目录由各自宿主管理，本轮不迁移、不改写这些数据。

## 实现

- 权威数据：`DSH_HOME/workbench/sidebar-spaces/workbench.sqlite`，正式便携路径为 `G:/DSH-3-Portable/Data/DSH/workbench/sidebar-spaces/`。不放在插件目录或桌面版本槽中。
- 旧数据：先读取当前浏览器地址的原知识/表格数据，事务初始化宿主存储；原 localStorage 不删除、不改写。重复迁移返回现有宿主版本，不覆盖已更新数据。
- 历史端口限制：浏览器不能跨 origin 读取别的端口。无法据此声称已经找回所有过去隐藏的记录；需从原地址导出或另做只读恢复审计。
- 并发：保存必须携带读取版本，`BEGIN IMMEDIATE` + revision 检查防止两个窗口静默覆盖。409 时保留编辑草稿，禁止自动强写。
- 恢复：事务内保留上版与初始迁移数据；事务前先写独立 JSON 快照并 fsync / 同卷 rename。备份失败或 SQLite 提交失败不发布成功。坏库不自动替换为空库。
- UI：读取失败不开放编辑；保存成功才关闭编辑和更新数据；保存未确认会提示先保留草稿再重新读盘。表格文本在失焦时提交。
- 安全：复用同版本 `connection.requestRejection()`，精确 Origin 检查、自定义请求头、JSON、完整 UTF-8 请求上限 8 MiB、15 秒读超时；未认证请求拒绝。插件卸载先注销路由、结束未完成请求，再等待其完成。
- 部署：仅插件代码、包文件清单、测试与文档；无 Electron src 改动，不生成或修改正式 A/B 候选。
