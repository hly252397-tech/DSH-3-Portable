# 更新按钮进度细线修复（2026-09-27）

状态：源码已修改，定点及独立离屏验证通过；未打包、未暂存、未激活，不改当前槽，不重启应用。

问题是更新按钮的低进度实心扇区呈细竖线；证据是用户截图 `codex-clipboard-2fcbab78-437c-4303-ab49-8a6029fa55e3.png`、现役 9ea0 槽 `resources/shell.html` 的 `::before` 无挖空遮罩且所有 busy 阶段共用扇区；下一步是仅修显示层并补状态/视觉对照测试。

## 范围与关联

- 源码：`assets/shell.html`；标准交付映射为候选槽 `resources/shell.html`，不是 `app.asar`。
- 写者：`renderDesktopUpdate`，读取既有 `status.kind/overallProgress`；不另建更新状态机。
- 链路：`#update-btn` → `check-updates` 桌面动作 → 后端更新状态 → `renderDesktopUpdate` → CSS。后端与 IPC 不改，状态演示不冒充真实下载测试。
- 预期：checking/其他无确定进度阶段为旋转圆环；downloading 为空心进度环；非 busy 状态清除进度，保留 available/ready 与 error/rolled-back 小圆点；completed 不留绿色常驻提示。
- 不改：现役槽、Profile、主进程、依赖、安装/回滚、设置页失败与构建清理机制。相关独立问题另行处理。
- 小型样式修复，使用以下影响矩阵，不扩大为中大型重构。目标 assets 与 HEAD 无差异；工作区其余大量 dirty 改动保留。

| 会碰谁 | 最可能的坏法 | 提前发现方式 |
|---|---|---|
| 更新图标 | 圆盘遮挡图标、低百分比仍有竖线 | 旧/新相同状态渲染，中心透明及低进度截图 |
| 更新按钮 | 伪元素截获点击、busy 禁用丢失 | pointer-events:none，状态禁用与动作断言 |
| 终态与下一轮 | 上一轮进度/旋转残留，错误提示丢失 | 连续阶段切换、错误/回滚/完成回归 |
| 主题/缩放/减少动态 | 深色不可见或缩放越界、仍旋转 | 独立渲染矩阵，不操作用户窗口 |
