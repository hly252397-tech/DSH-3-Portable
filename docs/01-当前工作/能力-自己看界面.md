# 能力：自己看界面（DSH 便携版3）

> 立此存照的原因：2026-09-15 用户明确要求「自己看界面这个能力你一定要记住」。
> 背景：此前改完界面我一律让用户重启后替我验收，甚至让他右键查元素——**这是把活推回客户，是指挥方心态**。

## 一句话

改完界面，**自己抓应用窗口看**，不把验收（尤其审美判断）推给用户。

## 怎么用

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File G:\DSH-3-Portable\scripts\look-ui.ps1 -NarrowWidth 1100
```

- 产出 `Data\Temp\ui-wide.png`（原宽）与 `Data\Temp\ui-narrow.png`（窄档）
- 脚本自动：把窗口提到最前 → 只抓**应用窗口矩形** → 测窄档 → **恢复原窗口尺寸**
- 抓完用 `read_image` 自己看；看不清就裁剪 + 最近邻放大再量

## 铁律（每条都是踩过的坑）

1. **只抓应用窗口矩形，绝不抓整屏**——抓整屏曾抓到用户其它应用的登录框（含隐私），当场删图并停用该做法。
2. **抓完核对内容**——别的窗口可能遮挡；图文不符就重抓，不拿它当证据。
3. **测完恢复窗口**（脚本已做），别让用户回来发现窗口被动过。
4. **本地图片别用 `file://` 预览**——应用侧栏是浏览器，开本地路径会裂图。要预览就走 http：
   `Data\Temp\icon-server.cjs`（静态服务，`http://127.0.0.1:61800/<文件名>`）+ `sidebar_open`。
5. **看图只用于定位，结论要量化**（像素边界 / DOM 尺寸 / 提交比对）；"我看着像"不算证据。
6. **审美自己判**——用户原话：「你做你认为不好看，你就做」。做好了自查，好看才收，不好看自己改。

## 不猜选择器（三次翻车的教训）

- 黑洞图标我按 `aria-label*="黑洞"` 找 `<img>` → 全落空：实测它是插件源码里**内嵌的 WebP data-URI**（`dsh-black-hole/lib/client.js` 的 `BANNER_IMAGE`）⇒ 改用 **base64 前缀精确命中**才对。
- 取真名的两条路：**读插件源码**（离线、快）／**起 `dsh web` 诊断实例查 DOM**（准，但连发重脚本会卡死，只发极小查询）。
- 取不到真名就**不写选择器**——宁可不做，也不猜。

## 相关教训（同类，一起记）

- `font-size: 0` 收文字**要连后代一起压**：文字在带显式字号的后代里时，父级压字号无效（专家/PUA 没收起就是这个原因）。
- `flex-wrap` + `margin-left: auto` = **自造换行**：auto 外边距抢走整行剩余空间，把右侧簇提前顶到第二行。
- **外壳 CSS 搬不动元素**：`position: absolute` 只能"盖"，不能把元素搬进另一个容器（曾把状态行压糊）。
- 改动是否生效要**看部署态**：`Data\Updates\Desktop\pointer.json` 的 `current` + 运行进程槽 + 槽内制品核对；候选就绪 ≠ 已生效。
