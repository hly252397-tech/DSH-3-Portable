# 上游 v1.0.63 吸收评估（2026-09-16）

## 抓取方式（本轮踩的坑与解法）

- **直连 GitHub 不通**：`git fetch upstream --tags` 报 `Recv failure: Connection was reset` / `Failed to connect to github.com port 443`（本机无代理环境变量；web_fetch 也失败）。
- **解法：镜像代理**。以下两条均可用，用 `insteadOf` 把 github.com 重写到镜像：
  ```
  git -c http.sslBackend=openssl -c url."https://gh-proxy.com/https://github.com/".insteadOf="https://github.com/" \
      fetch upstream "refs/tags/v1.0.63:refs/tags/up-v1.0.63"
  ```
  （`ghproxy.net` 同样可用。）
- **必须用带命名空间的 ref**：本地已存在 `v1.0.63`（**便携仓库自己的发布标签**，非上游提交），直接 fetch 会被拒绝
  （`would clobber existing tag`）。故抓进 `up-v1.0.62` / `up-v1.0.63`，**按 commit 对比，不看标签名**。
