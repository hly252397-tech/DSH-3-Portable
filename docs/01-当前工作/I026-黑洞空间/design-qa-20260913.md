## 对照结论

第 2 张效果稿的黑洞模块结构已落地并继续高级化：深色天文成长横幅、L0/成长值/知识成长说明、待机状态、知识密度仪表、最近吸收/复用潜力摘要、总览/记忆 tabs、状态筛选、左侧资料列表、右侧正文阅读和确认/引用操作。针对真实 DSH 右侧 617px 面板，摘要卡保持一行，阅读区提前出现；重新打开黑洞时自动回到横幅顶部。素材实际从便携盘内嵌 WebP 读取，未发起网络请求。源码使用安全的 Markdown 子集渲染，未使用 `dangerouslySetInnerHTML`。

效果稿左侧是一个特定对话，实机当前会话没有打开同一对话，因此左侧宿主内容和提醒状态不同；这是比较状态差异，不是黑洞模块差异。黑洞工具条在实机仍位于输入卡片正上方，并通过现有 composer 宽度令牌对齐。

## 必检表面

- Typography：沿用 DSH 字体体系，正文 14px、标题层级清晰，资料标题不再显示原始 Markdown `**`；详情增加档案编号、类型和摘要层。
- Spacing/layout：横幅、资料列表和详情区按单一阅读列排列；宽屏双栏、窄栏上下排列；实测无横向溢出。
- Colors/tokens：宿主保持浅色，黑洞横幅使用深色素材，紫色仅用于主要操作和选中状态；待确认/已确认有语义色。
- Image fidelity：独立 WebP 为离线发布素材，1536×512、35,582 bytes；源码和实际 Profile 一致。
- Copy/content：成长值明确写成“知识成长 · 非模型智商”；模型配置继续禁用并说明当前边界。
- Interactions：吸收资料打开/取消、空间选择、tabs、搜索、状态筛选、手册、智力配置均已运行验证；确认/引用保留真实入口，QA 未触发会修改用户资料或发送消息的动作。
- Accessibility/responsive：按钮与输入保留语义控件、焦点样式和 reduced-motion 规则；80/125/150% 与 1100×800 未出现横向溢出。
