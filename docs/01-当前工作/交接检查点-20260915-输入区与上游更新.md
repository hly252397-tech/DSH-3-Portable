## 三、已排除 / 教训（别再犯）

1. **外壳 CSS 无法把元素搬进另一个容器**：`position:absolute` 只能"盖"上去（曾压糊状态行）。真要搬进别的行 ⇒ 只能改插件 DOM，或接受现状。
2. **`margin-left:auto` 在可换行 flex 里会抢走整行剩余空间**，反而把右侧簇提前顶到第二行（曾自造两行）。
3. **`nowrap` 必须同时定收缩优先级**（chips `flex:0 0 auto`），否则 chips 互相挤压重叠。
4. **改布局前先确认对象**（曾把"模型显示"的诉求误做成 PUA）。
