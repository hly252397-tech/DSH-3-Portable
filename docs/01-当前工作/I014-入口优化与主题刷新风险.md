## 已实施边界

- 仅改本地插件 `lib/client.src.js` 与生成的 `lib/client.js`，同步到实际 `node_modules/dsh-sidebar-spaces/lib`。
- 复用现有 Settings 导航适配方式；读取了当前运行时 settings / sidebar 的槽类型，footer 没有公开的 openSection 回调。没有导入其他插件内部 React 组件或修改官方包。
- 精确匹配设置触发器和目标分区，支持延迟挂载、超时错误、取消、重复点击取代旧请求和插件处置清理。失败不声称打开成功。
- 自动化独立 Tab 自动进入实际管理页，失败时保留错误与重试；侧栏直接发起目标导航。
- 未实现独立扩展中心、自动化执行可靠性、真实编码 / 通用模式切换、知识库首页导入入口、活动图月份排版、主题刷新生命周期修复。
- 模型可见输入、Host 路由、权限、Profile、会话日志和知识存储不变。

## 下一轮优先级与验收条件

| 优先级 | 优化项 | 验收条件 |
| --- | --- | --- |
| P0 | 主题刷新与热更新生命周期 | 刷新 / 热更新后原主题、侧栏和活动图均保留；不触发待升级；与同尺寸原截图比较 |
| P0 | 更新入口区分 | 用户能区分刷新界面、重载服务、升级运行时；有待更新时明确提示影响 |
| P1 | 扩展入口细化 | 入口可直达插件、技能、连接器；设置保留全局偏好；不靠重复通用页 |
| P1 | 知识库概览操作 | 概览明确进入库和导入路径；导入预览、保存失败及取消路径可验收 |
| P1 | 真实模式开关 | 接入真实模式状态；不可只用 CSS 文字暗示可切换 |
| P2 | 字体和活动图布局 | 月份不换行，表单与列表字体一致，小窗口无横向溢出；补键盘 / 对比度验证 |
