# I018：侧栏重复入口去重

日期：2026-09-05

## 用户可见结果

- 保留 DSH 侧栏顶部的放大镜；它继续打开官方会话搜索。
- 删除侧栏底部由 `dsh-sidebar-spaces` 重复注入的“搜索任务”入口。
- 保留侧栏“自动化”，直接打开已安装自动化插件的任务管理分区，不再先打开空白中转工作台。
- 保留左下角“设置”全局入口，其配置覆盖范围高于单一功能的快捷入口，不能为了去重隐藏。
- 知识中心、扩展及任务搜索、自动化、设置功能本身不删除。

## 实施边界

仅移除 `sidebar.footer.action` 中 `dsh-task-search` 的重复搜索注册。恢复 `dsh-automation` 快捷入口，复用既有可取消的 `SidebarSettingsAction` 导航到自动化管理分区；保留上方定时任务入口，不在未确认完整行为等价时删掉它。恢复官方 `sidebar.settings` 的正常可视容器，撤销离屏代理 CSS 与 `aria-hidden`。没有修改 DeepSeek Harness 运行时、自动化任务存储、会话数据、知识库、模型输入或桌面 A/B 指针。本地副本与实际安装副本同步。

## 本次纠错与入口权重

- 设置是全局配置入口；自动化是任务管理快捷入口。一个是功能的配置容器，一个直达特定分区，两者不能只按截图圈选或落在同一窗口就一并删除。
- 去重前先核对入口归属、实际目标、功能覆盖范围及剩余可达路径；优先保留全局与高频入口，不以减少按钮数量作为验收目标。
- 前次“隐藏设置代理成功打开”的验收结论撤回：DOM 存在或 `offsetParent` 非空，不能证明组件可见、未被遮挡和能够点击。旧 `sidebar-search-dedup-20260905` 报告仅是历史错误证据，不能作为当前验收依据。
