# Qoder 功能跟进任务单

核验日期：2026-09-05。本表区分实际可用能力与外观占位，不以界面相似代表功能一致。

## 本轮完成的插件实现

| 功能 | 实现和验证边界 |
| --- | --- |
| 多知识库 | 创建、重命名、条目分库和移动；只允许删除空库，禁止连带删除知识；真实隔离 Profile 操作通过 |
| 旧知识迁移 | 原有条目归入“工程手册”；保留 ID、正文、标签；迁移幂等测试通过 |
| 条目保存 | 取消草稿不写入；保存成功才关闭编辑；存储失败保留原数据并显示错误 |
| 工作区范围 | 从当前运行时 Workspace Controller 读取真实工作区，支持库可见范围；此为界面筛选，不是访问控制或 AI 检索绑定；多工作区实测待补 |
| 备份导入 | 保留知识库结构，按 ID 合并、不覆盖现有；校验条目结构；现有导出包含 collections |
| 自动化 | 新入口打开已安装插件的“定时任务”管理页；实际导航已验证；本轮未创建或触发模型任务 |
| 首页图表 | 移除示意颜色，读取 Session Controller 的真实非空任务最后活动日期；标题改为“任务最近活动分布”，不冒充每日执行次数 |

## 决策与风险

复用现有自动化插件管理页，不复制其内部 React 组件或实现第二个调度器。知识库采用增量 collections 字段，避免删除旧存储或替换会话；浏览器存储尚不是跨版本持久化的最终方案。

修改仅限 sidebar-spaces 客户端和验证脚本、文档。未变更 Electron src、Profile 清单、运行时版本和桌面 A/B 指针。开始时存在待切换候选 `1.0.46-local-9ce60671cf7bd302`，保持不动。正式应用进程未终止。
