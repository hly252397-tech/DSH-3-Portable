# I027：P3 Tiny 二手行情监控插件

状态：**候选实现已提交，等待本机真实 Profile 安装与 DSH Loader 验收**

## 目标

为 DSH 便携版 3 增加本地插件 `dsh-p3-tiny-watch`，默认每周检查 Lenovo ThinkStation P3 Tiny 的公开二手货源；可信单机到手价不高于 1500 元、批量单价显著偏低或同一货源明显降价时记录并提醒。

## 本轮边界

- 插件源码进入 `plugins/dsh-p3-tiny-watch/`，不把运行数据提交到 Git。
- `scripts/install-p3-tiny-watch.mjs` 将源码事务式复制到真实 Profile 的 `local/`，写入 `link:` 依赖与 bundle，并建立 `node_modules` Junction。
- 安装器不执行 `pnpm install`，避免已知的 Profile 插件矩阵被意外整体升级；运行时使用已验证的目录链接形态。
- 不修改 `src/**`、官方 DSH 包或现有社区插件。

## 当前结论

纯逻辑单元测试和模拟 Profile 安装已通过；由于当前执行环境无法访问用户电脑的 `G:\DSH-3-Portable\Data\...`，尚未完成真实 Loader ACTIVE、命令 UI、桌面通知及 `startup-error.log` 验收，不能标记正式完成。
