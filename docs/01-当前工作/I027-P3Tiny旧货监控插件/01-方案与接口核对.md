# I027：方案与接口核对

## 插件形态

- 包名：`dsh-p3-tiny-watch`
- 入口：`lib/index.js`
- Bundle：`cordis.patch.yml`
- 合法导出：命名导出 `name`、`inject`、`Config`、`apply`
- 必需服务：`commands`
- 可选能力：Cordis `ctx.timeout` / `ctx.interval`；缺失时保留手动命令，不让插件进入 PENDING。

## 使用的现有契约

1. `ctx.commands.register({ name, description, input, handler })` 注册四个用户命令；注册通过 `ctx.effect` 归属插件 Fiber。
2. Cordis timer 提供可处置的 `ctx.timeout` 与 `ctx.interval`，用于周期到期检查；不直接创建裸 `setInterval`。
3. DSH Portable 子进程已有 IPC 通知消息：`{ type: 'notify', kind: 'turn-complete', sessionId, title, body }`。插件只在 `process.send` 存在时发送；CLI/测试环境自动降级。
4. 数据写入 `$DSH_HOME/plugin-data/dsh-p3-tiny-watch/`，采用临时文件 + 同目录改名。

## 数据采集

- 只访问配置中的 HTTPS URL。
- 拒绝 localhost、回环和常见私网地址。
- 默认允许 eBay 公开域名。
- 支持 JSON feed、JSON-LD Product/ItemList 和有限的 eBay 搜索卡片解析。
- 不读取 Cookie，不绕过登录、验证码或反爬，不保存完整页面正文。

## 已知限制

- eBay 页面结构变化或反自动化响应可能导致来源错误；错误会记录，不伪造行情。
- 默认汇率是可配置估算值，不代表实时结算汇率。
- 中国平台登录后页面首版不自动抓取。
