# 20260920-设置窗口与黑屏事故复盘（防复发清单）

> 一晚三连事故的根因复盘与防复发规则。适用于此后所有外壳/UI/桌面进程类改动。

## 事故链

1. **设置窗口溢出**：新窗口未给坐标，Windows 对带父窗口的新窗口做系统级摆放覆盖编程定位；约束器只在主窗口移动时纠偏。单测全绿（假环境模拟不出 OS 行为），build.8 真机首秀翻车。
2. **二次点击不生效**：9/18 的“切换行为”只退出 DSH 网页内设置页；用户点的是打开**独立桌面设置窗口**的图标，旧逻辑不关窗口。叠加读图工具当晚失灵，基于幻觉描述做错两轮修改。
3. **黑屏**：旧实例异常退出后 node 子进程（harness/桥接）未被回收，孤儿死占 3082/3083 端口长达 12 小时；新实例桥接失败 → 外壳拿不到 DSH 地址 → 黑屏。启动器健康检查只验进程存活，而响应检查的正是孤儿 → 每次都放行。

## 防复发规则（强制执行）

1. **UI 行为修复必须自测闭环再交付**：自动化实测（窗口枚举 + 坐标数学验证 + 开→关→开→关循环），不把验收推给用户；用户确认仅作补充。
2. **读图工具失灵时立即切换结构化取证**：无障碍树 / `list_windows` / OCR / 像素检测。禁止基于视觉模型的幻觉描述做判断或改代码。
3. **行为歧义先问清**（给选项的提问），一次问清方向再动手；方向错了的 40 分钟构建是最贵的浪费。
4. **构建前四查**：git 快照与候选内容清单（明确带着谁的在途改动）、无并发构建、回收区排空、`pointer.json`/`state.json` 事务状态。
5. **新功能必须实机验证**：单测绿 ≠ 真机对（OS 窗口摆放、进程生命周期等行为无法在假环境复现）。
6. **技术护栏（已落地）**：`src/orphan-sweep.ts` 开机自清扫孤儿 harness/桥接。后续可选加固：主进程退出时回收子进程树；启动器健康检查绑定“端口归属本进程树”。
7. **共享状态纪律**：撞他方会话在途改动不背书、如实报漂移；多会话并行时改动前先声明范围。
