# 20260918-对话区截断根治

## 问题
右侧工作台面板打开时，对话区被面板截断（面板比预留空间宽）。
方案 A（layout.css 的 CSS clamp）只钳制了 `#root` margin-right，但面板 inline style.width 仍写原始拖拽值——两个宽度驱动值漂移。

## 根因
`applyDrag` 设 inline `style.width = ${width}px`（原始值），`writeGeometry` 写 `--dsh-sidebar-width`（有 avail-680 钳制）。seam-exact CSS 的 `width:var(--dsh-sidebar-width)!important` 在无 editorPlaceholder/paneEmptyCards 时被 inline style 覆盖（inline + important > stylesheet），面板实际宽 = 原始值，而 `#root` margin = 钳制值。

## 修复
在 `applyDrag` 入口加同样的 avail-680 钳制，让 width/height 进来就钳制，后续 inline style、bottom push、writeGeometry 全用钳制值，三处恒等。

## 文件
- `scripts/build-sidebar-layout-compat.mjs` — 新增 applyDrag 钳制注入
- `Data/DSH/profiles/web/local/dsh-better-sidebar/lib/client.js` — 构建产物（钳制已注入）
- `Data/DSH/profiles/web/local/dsh-better-sidebar/src/client/layout.css` — 方案 A CSS clamp（保留作安全网）
