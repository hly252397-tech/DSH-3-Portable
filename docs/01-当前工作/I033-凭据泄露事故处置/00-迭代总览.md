## 2. 教训（供后续 agent，比处置本身值钱）

1. **禁止用裸关键词 grep 凭据类路径。** 搜"令牌"必须匹配带赋值符的模式（`token=`），并**先排除**
   `.credentials.yaml` / `.npmrc` / `.env` / `*token*` 这类文件；输出一律脱敏（前 24 字符 + 长度）。
   本次的失败形态是"匹配太宽 + 直接打印整行"。
2. **压缩格式不能用明文 grep 证明"不存在"。** 会话日志是 `session.v3.jsonl.zstd`
   （zstd 魔数 `28 B5 2F FD`）：**任何明文都 grep 不到**。凡用 grep 做否定性结论，必须先跑
   **已知存在的对照字符串**验格式——本次对照 `9c27219f3b6264c7`（当天确定打印过）同样 0 命中，
   由此当场判定"未命中"结论无效并撤回。**没有对照的"未命中"不是证据。**
3. **进程内令牌在设计上不可发现。** `dsh web` 的令牌是 `randomBytes(32)` 进程启动时现生成、
   只存内存、**从不落盘**（进程命令行只有 `--port 0 --no-open`）。"找一个必然存在的令牌"本身就是
   **错的问题定义**——正确做法是**自己起一个实例**用它自己打印的令牌：
   `<外壳槽>\resources\node\node.exe <外壳槽>\resources\bootstrap.mjs <运行时槽>\node_modules\@deepseek-ai\dsh\lib\bin.js web --port <p> --no-open`
   ＋ `DSH_HOME` / `DSH_PROFILE_DIR` / `DSH_PROFILE_NAME=web` / `DSH_RUNTIME_DIR` 四个环境变量，
   stdout 会打印 `dsh web: http://127.0.0.1:<p>/?token=…`。
4. **自起实例量不到桌面窗口的几何。** 自带浏览器里的视口尺寸与桌面窗口内那个
   WebContentsView 不同，数字不可比：要判"占位更宽还是视图放置"必须在桌面窗口内量
   （截图按像素量 / 把浏览器窗口调成与桌面视图同尺寸 / 由外壳开 DevTools 读 `innerWidth`）。

## 4. 相邻会话独立复核（2026-09-14 深夜，补上第 3 节的问号）

> 方法：写了一个**多帧 zstd 读取器**（`宏建云系统/_diag/zstd-read.mjs`）——`session.v3.jsonl.zstd` 是**多帧**压缩，
> Node 的 `createZstdDecompress` **只解第一帧**（1 MB 的记录只出 205 字符），逐帧切分后单个文件可解出 317 帧、
> 2.8 M 字符、**每行都能 `JSON.parse`**。据此重跑了本文件第 2 节列出的"压缩文件内的结论无效"的那部分。

| 步骤 | 结果 |
|---|---|
| 覆盖范围 | `Data\DSH\sessions` 全部 13 个记录（3 个项目目录），**解压后 38,892,756 字符**，0 跳过 |
| **阳性对照**（先证明仪器有效） | `9c27219f3b6264c7` 183 处、`dsh-agent-boundary` 669 处、`systemPrompt` 356 处、`base64` 182 处 ⇒ **仪器有效** |
| 定向模式（`sk-*`/`AIza*`/`ghp_*`/`Bearer`/`"apiKey":"…"`） | **0 命中** |
| **形状审计**（只有长度，不出内容） | `sk-*` 共 305 处：0-9 字符 272、10-19 字符 33、**≥20 字符 0**；`AIza*`/`ghp_*` 全 0 ⇒ 出现的全是**讨论中的前缀提及**，没有密钥量级的串 |
| 键名/路径提及 | `QWEN_TOKEN_PLAN_CN_API_KEY` 30 处、`.credentials.yaml` 154 处（与"事故被反复讨论过"一致） |

**结论（限定范围，不越界）**：在**已落盘**的 13 个会话记录里，**没有密钥值本体**；第 2 节"压缩文件内的结论无效"这一限制
现在有了可用仪器，定向 0 命中 + 形状审计 0 处 ≥20 字符，是**带对照的可采信结论**。
仍然**不声称"本机已无明文"**：未落盘的当前轮、代理缓存、`Data\Temp\diag-home`、其它 home 目录都不在本次覆盖内。
**轮换仍是唯一根治**（本文件的处置口径不变）。

### 4.1 给后续审计者的两条补强

1. **"关键词命中" ≠ "值存在"**：`sk-sp-` 有 69 处命中，但**没有一处 ≥20 字符**——它们全是文档/讨论里的前缀提及。
   凡做否定/肯定结论，必须同时给**阳性对照**（已知存在的串）与**形状判据**（长度/字符集），否则两个方向都会错。
2. **图片资产会被误判成密钥**：`dsh-black-hole/lib/client.js` 内嵌 46 KB base64（`@black-hole-art`，解码前 16 字节
   `52 49 46 46 … 57 45 42 50` = RIFF/WebP）。它出现在工具输出里时，观感与"泄露密钥"完全一样 ⇒
   报告疑似泄露前先解码头部魔数，并对所有输出做掩码。
