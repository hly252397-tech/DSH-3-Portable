## 最可能的解释（按嫌疑排序）

1. **本会话自己的测试基建污染了用户体感窗口**（诚实归因）：时间线实证——16:00–16:07 v5 代际 1GB 拷贝；16:08/17:08/18:22/18:58 我四次对**同一 v5 家园** boot 探针 harness 实例（每次 10–20 秒多核启动 + G: 盘读 + im-connect 重附着 3.5s + 全插件装载，18:59 实测 harness 峰值 3.55 s/s），全部落在用户 16:34 重启后的使用窗口内。用户在探针启动/大拷贝期间切界面，会真实感到卡顿。**这些后台源现已全部清除**（探针进程已杀、浏览器页已关、无未完结后台任务）。
2. **工作台"接管"手感**：进入宏建云工作台后整个界面被替换（DSH 侧栏消失、外壳返回无效），"切不过去"的手感与"卡断"吻合——退出方式是 **Esc**。若用户不知 Esc 退出，会以为切换卡死。
3. 偶发 harness 尖峰（会话装载流式写入、im-connect attach）：实测 1–3.5 秒级、低频，属正常量级。
