## 本轮 Q02：活动任务批量归档

- 入口：现有侧栏任务树上方“批量归档”，勾选后“确认归档 N 项”。不新增归档管理页。
- 数据：调用已安装 `@deepseek-ai/dsh-client-ui-workspace` 公开的 `archiveSession(sessionId): Promise<void>`；其约定为保留日志和记账，仅加入全局归档集合。
- 安全：排除已归档、运行中、待审批 / 待回答 / 待计划审阅、空白、频道与子 Agent 会话；每项执行前重新检查客户端最新状态。仍可能存在检查后到宿主提交之间的状态竞态，未宣称宿主原子锁。
- 执行：串行、去重、防重复点击；失败项保留勾选可重试，成功 / 失败 / 跳过分别计数。恢复沿用“设置 → 已归档”。
- 修改范围：仅 dsh-codex-ui Client 及测试、需求台账；不修改 Harness 内核、桌面 ASAR、A/B 指针或正式对话。
- 规范：已验证在线官方基线；核对安装版 ui-workspace README 与 slot contract，不引入新 SDK 依赖。
- 验证状态：实现待验。测试证据统一在 `artifacts/batch-archive-v3-20260905/`；本段待实测完成后更新，不提前宣称正式窗口生效。
