# 首页活动卡片与输入框尺寸对齐

日期：2026-09-08。用户指出首页活动分布与输入框宽度不一致，要求统一宽度、优化高度，并在放大缩小时保持相同比例。

## 原因与实现

原活动卡片使用独立的 768px 上限；输入框另外消费会话宽度变量及两侧 clearance。Qoder 预设又单独设置了顶部留白、固定最小高度与输入框自动外边距。两套尺寸和留白规则在侧栏开关、窄窗口及主题切换时产生差异。

在 `local/dsh-sidebar-spaces/lib/client.src.js` 增加统一的首页布局层 `HOME_CARD_ALIGNMENT_CSS`，由现有插件样式生命周期加载，并覆盖两种布局的旧几何规则：

- 两张卡片共用同一内容列，最大内容宽度 768px；主区域变窄时同步适配，统一左右留白。
- 使用共同的容器尺寸单位控制高度，常规空白状态下活动卡片 150–160px、输入框 120–128px，高度比为 5:4。内容列不超过 560px 时两者同步调整为 200/160px，为换行工具栏保留空间；不超过 240px 时为 250/200px，并减少月份标签显示密度。
- 首页右侧栏最多占视口宽度的 45%，同时限制面板宽度和主区域预留空间，避免记忆的像素宽度在窗口缩小或界面放大后挤压主内容。
- 中间间距统一为 16px，移除活动卡片额外下外边距以及输入框的自动间距；收紧首页固定最小高度。
- 统一边框及圆角，减弱输入框大范围阴影。活动网格自适应高度，月份标签仍与同一组 52 周列对齐。
- 文字和附件增多时输入框可以自然增高，宽度继续对齐；不通过缩放整块 UI 或裁剪内容维持比例。
