# 侧栏紧凑图标轨

## 决策

采用官方 codex-ui 已有的 compact shell 作为便携版默认侧栏形态。侧栏底部只保留设置；重启沿用桌面外壳动作，移动到顶部返回箭头左侧，避免展开态被压缩成窄宽后留下横向卡片。

## 改动

- assets/theme.css
  - 将 .dcu-root 收敛为 56px 图标轨。
  - 隐藏展开 shell，显示官方 compact shell。
  - 隐藏侧栏 footer action，只保留设置入口，并修正设置图标在 56px 轨内左对齐。
- assets/shell.html
  - 将重启按钮移动到顶部返回箭头左侧，保留原两步确认和宿主重启调用。
- test/workbench-panel-clamp.test.ts
  - 增加 compact shell、56px 宽度和 footer 图标动作的静态回归检查。

## 复验补充（2026-09-13）

用户反馈截图显示窄窗口仍有约 252px 的空白侧栏宿主，且“设置”文字被挤到宿主右边。前一轮验收只断言 `.dcu-root` 的宽度，未断言外层 `.pI_x6G_frame` 网格列，结论不完整，按用户截图判定前一轮验收失败。

- 根因：窄窗口重新计算官方工作台网格时，侧栏内层已切到 56px，但外层第一列仍可能保留宽侧栏轨道。
- 修复：`assets/theme.css` 对包含 `.dcu-root.dcu-compact` 的 `.pI_x6G_frame` 明确设置 `grid-template-columns: 56px minmax(0, 1fr) auto`，并将直接宿主 `.pI_x6G_sidebarCol` 的宽度、最小宽度、最大宽度全部钳到 56px；设置按钮增加 `overflow:hidden`，避免文字越出图标轨。
- 回归：`test/workbench-panel-clamp.test.ts` 增加外层网格和宿主宽度静态断言；`artifacts/current-runtime-qa/electron-qa.cjs` 增加真实 DOM 网格列、宿主宽度、设置按钮溢出断言。
- 真实验收：宽窗口当前候选槽实测 `.pI_x6G_frame` 第一列 `56px`、`.pI_x6G_sidebarCol` `56px`，底部只显示设置图标且无文字越界；截图与 JSON 证据为 `artifacts/current-runtime-qa/sidebar.png`、`artifacts/current-runtime-qa/results.json`。此前源码运行时动态缩至 360px 窄窗口也实测第一列与宿主均为 `56px`，相关测试 4/4 通过。
