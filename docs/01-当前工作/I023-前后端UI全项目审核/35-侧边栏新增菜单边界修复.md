# 侧边栏新增菜单边界修复

## 原因

侧边栏顶部“+”新增标签菜单使用 portal 挂载到 document.body，并以 align="end" 向按钮左侧展开。菜单因此越过侧边栏左边界，覆盖主内容区。

## 改法

- Data/DSH/profiles/web/local/dsh-better-sidebar/src/client/TabBar.tsx
  - 保留 portal，避免被 tab 横向滚动容器裁掉，修复“点击后打不开”。
  - 新增标签菜单改为 align="start"，从“+”按钮向侧边栏内部展开。
  - 标签右键上下文菜单保持 portal，不改变其按鼠标坐标定位的行为。
- Data/DSH/profiles/web/local/dsh-better-sidebar/lib/client.js
  - 同步实际 Profile 加载的编译产物。

## 验收证据

- 2026-09-13：verify-dsh-official-baseline.mjs --online PASS。
- 2026-09-13：二次修复后静态核对源码和编译产物，新增标签菜单与标签右键菜单均保留 portal，新增标签菜单为 align="start"。
- 2026-09-13：ui-baseline.mjs 被既有无关漂移阻断：Data/DSH/profiles/web/local/dsh-restart-button/lib/client.js，本轮未修改该文件。
- 2026-09-13：第一次取消 portal 后出现“菜单打不开”，原因是菜单被 tab 横向滚动容器裁切；已恢复 portal。
- 待用当前 rc.2 页面入口实际点击“+”并检查窄侧栏、缩放和双面板状态下的可见边界。
