## 3. 为什么保留一个 `retireHeroActivityGrid`

```js
function retireHeroActivityGrid() {
  const purge = () => {
    for (const host of document.querySelectorAll("[data-dss-activity-host]")) host.remove();
  };
  purge();
  const observer = new MutationObserver(purge);
  observer.observe(document.body, { childList: true, subtree: true });
  return () => { observer.disconnect(); purge(); };
}
```

`ctx.effect(retireHeroActivityGrid, "dsh-sidebar-spaces: retired hero activity grid")` 取代原来的挂载 effect。
理由是**旧版本或热重载可能残留宿主节点**：宿主是运行时 `insertBefore` 进 `.wSkVaW_composerHero` 的普通 div，不在模板里，插件卸载不会自动清掉，留着就是一个空白块。监听成本与原来的 `mountHeroActivityGrid` 相同，不是新增开销。

## 4. 基线影响

`--dss-home-card-height: calc(15 * var(--dss-home-unit))`（= 120px）**保持不变**，输入卡 `.uV2eYG_card { min-height: var(--dss-home-card-height) }` 继续沿用。
活动宿主原有 `order: 2`，composer 与 `.uV2eYG_root` 是 `order: 3`、`.wSkVaW_heroWorkspaceRow` 是 `order: 4`。移除 order-2 元素不影响其余项顺序，也不会留空档（flex order 只排序，不占位）。

docs 06/15/19/21 里「双卡等高」的说法此后只剩输入卡一张，**该约束不再有配对语义**，但变量与 120px 值继续生效，未做其它改动。
