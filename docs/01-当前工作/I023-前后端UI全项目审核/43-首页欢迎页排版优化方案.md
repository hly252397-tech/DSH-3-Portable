## 0. 结论先行

截图这屏"不整齐"的主因**不是缺微调**，而是**首页的整套排版规则已经整块失效**（§1 有实测证据）。
因此方案分两层：**P0 修复作用域**（不修则后面所有微调都落不到），**P1 视觉精修**（§3 的 7 项）。

## 1. 根因：首页基线 CSS 有一半处于失效状态

首页的"便携版基线"由两段 CSS 组成，都在 `Data/DSH/profiles/web/local/dsh-sidebar-spaces/lib/client.src.js`：

| 常量 | 行号 | 作用域 | 现在是否生效 |
| --- | --- | --- | --- |
| `HOME_DETAIL_CSS` | 1797–1949 | `body[data-color-scheme][data-dsh-preset="qoder"]` | ❌ **整块失效** |
| `HOME_CARD_ALIGNMENT_CSS` | 1950–2059 | `body[data-color-scheme] .wSkVaW_root[data-phase="hero"]` | ✅ 生效 |

`HOME_DETAIL_CSS` 末尾（1949 行）有一句：

```js
.replaceAll('body[data-dsh-preset="qoder"]', 'body[data-color-scheme][data-dsh-preset="qoder"]')
```

即：**这 24 条规则只在 `data-dsh-preset="qoder"` 时才生效**。而「移除 Qoder 工作台主题」（`38-移除Qoder工作台主题.md`，2026-09-13）之后，预设只剩
`deep-sea / lake / verde / vermilion / slate / gold` 六个，**`qoder` 永远不会再出现**。

**盘上实测证据**：

- `Data/Electron/UserData/shell/theme.json` → `{"schema":1,"preset":"verde"}`
- `src/dsh-view-preload.cts:112,123` 把这个值写进首页文档的 `root/body.dataset.dshPreset`
- `assets/theme.js:42,44` → `current = 'deep-sea'`，`parse()` 对未知值降级为 `deep-sea`；`THEMES` 里已无 `qoder`
- 当前槽 `resources/theme.js` 与仓库 `assets/theme.js` sha256 相同、`qoder` 出现 **0 次**（本轮已复核）

⇒ `HOME_DETAIL_CSS` **恒不匹配**，首页现在处于「官方默认排版 + 半套便携版基线」的混血状态。

### 三个可肉眼验证的指纹（都与截图吻合）

| --- | --- | --- |

| 输入卡 | 1885 行 800px 宽 / 圆角 16px / 高 120px | 走 2012 行 816px / 圆角 12px |

## 2. P0：`HOME_DETAIL_CSS` 逐条取舍

不能无脑把 `qoder` 换成"任意预设"——那 24 条里混着 Qoder 专有视觉。逐条裁决：

| # | 规则 | 原值 | 处置 | 理由 |
| --- | --- | --- | --- | --- |
| 1 | `--dss-home-font` / `font-family` | Segoe UI + 微软雅黑 UI | **恢复** | 现在整屏用官方字体，中文观感与设置页不一致 |
| 2 | `--dss-home-width: 768px` | 768px | **恢复**（提到非预设作用域） | 基线变量，被 `--dsh-composer-card-max-width` 引用 |
| 3 | `.dcu-brand / .dcu-mode-label / .dcu-head / .dcu-foot` 等侧栏规则 | 侧栏品牌与菜单 | **恢复** | 与首页同批失效，属"连坐"漏网（需你核对侧栏现状，见 §4-C） |
| 4 | `.dcu-menu > button:nth-of-type(2..4) { display:none }` | 隐藏侧栏重复入口 | ⚠️ **待核对后再定** | 若侧栏现在多出三项，说明这条也该恢复 |
| 5 | `composerHero` 宽 800px、`padding: clamp(40px,20vh,170px) 16px 14px`、`min-height: max(610px,100dvh-10px)` | 标题垂直居下 | **恢复但调参**：`padding-top` 收小为 `clamp(32px,12vh,96px)`，`min-height` 改 `auto` | 20vh 在大屏把标题压得过低，是"上下留白不成比例"的来源 |
| 6 | `.pXSMma_headline { padding-top:90px; min-height:165px }` | 给品牌位预留 | **丢弃** | 这是 Qoder 品牌位的高度，不是通用基线 |
| 7 | `.pXSMma_previewBadge { display:none }` | 隐藏预览版徽标 | **丢弃**（改为保留但缩小） | 「预览版」是有意义的状态标识，不该藏 |
| 8 | `.pXSMma_fishHitbox { scale(1.7); absolute; top:10px }` | 放大鱼标 | **丢弃** | Qoder 视觉 |
| 9 | `.uV2eYG_card { min-height:120px; border-radius:16px }` | 输入卡 | **保 120px，圆角改 12px** | 基线与 `ROUNDED_PANEL_CSS` 的 `--dss-card-radius` 一致 |
| 10 | `order` / `margin-top:auto` 排序族 | 标题→卡片→工具行 | **恢复** | 决定各区块先后，缺了会串位 |

> **P0 一句话**：把 `HOME_DETAIL_CSS` 的选择器从 `[data-dsh-preset="qoder"]` 改为**不依赖预设**（`body[data-color-scheme]`），并按上表剔除 3 条 Qoder 专有视觉。
