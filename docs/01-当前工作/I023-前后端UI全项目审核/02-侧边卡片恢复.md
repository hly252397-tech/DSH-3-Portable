# 侧边卡片恢复

日期：2026-09-08。用户截图明确指向设置中的“侧边卡片”，插件为 `DSH-better-sidebar v0.18.0-alpha.0`。

## 根因与纠正

审核开始时的 Profile 快照已缺少 `dsh-better-sidebar`。上轮把这一缺失误判为可选替代左侧导航，没有恢复用户已有的右侧卡片能力；该判断已从功能清单和审核结论中撤销。它提供会话右侧/底部文件、终端、Git、任务、侧聊及扩展卡片，与 `dsh-codex-ui` 左侧导航职责不同。

恢复主插件后还复现了第二个问题：`dsh-sidebar-spaces` 仅在初始化时查询一次 `betterSidebar`，提供者稍后加载时，知识中心、数据库、Inventor 和自动化卡片没有注册。现改为使用实际 Cordis 的 `ctx.inject` 创建受生命周期管理的注册分支；服务出现时挂载，消失时清理，重新出现时恢复。独立知识工作台仍可在主卡片插件尚未加载时使用。

## 实施与数据边界

- 使用官方 CLI 先在隔离 Profile 验证，再为正式 `Data/DSH/profiles/web` 安装并启用准确版本 `dsh-better-sidebar@0.18.0-alpha.0`。
- 正式 Profile 的其他直接依赖及原有 bundle 全部保留；`Data/DSH/settings.yaml` 的 `dsh-better-sidebar` 配置块逐字保持一致，包括既有宽度与卡片开关；未处理原有待更新队列。
- 安装后核对并保留本地定制 Codex UI 客户端，确认工作模式、知识工作台的源文件与实际安装文件一致。
- 修改的是 Profile 插件和客户端，不修改桌面主进程或覆盖当前 A/B 槽。安装由既有 Profile 监测/加载机制生效；未强制结束用户桌面。
