# 底部面板开关恢复

2026-09-12，开发前诊断：真实 Profile 页面点击右上角底部面板按钮后，`bottomOpen` 已切换，但底部面板仍为 `visibility:hidden`、宽度 2 px。插件仅查找旧 `[data-slot="conversation"]` 的父节点；当前官方页面使用 `[data-slot="main"]` 包裹 `main.conversation`，因此对话列定位始终失败。另外本地圆角样式的 `margin:0!important` 会覆盖底部让位，需要一并恢复。

范围：本地 better-sidebar 分叉的对话列定位与布局 CSS，以及 sidebar-spaces 的圆角间距兼容。保留旧版定位路径，增加新版 main 插槽路径，不依赖哈希类名；开关、拖动、持久化仍使用既有状态机。无需新增后端（纯前端布局修复）。不改官方包和活动桌面槽。

验收待完成：真实按钮展开/折叠、面板内关闭、底部拖动、左右栏切换、缩放、刷新恢复；底部面板可见且不遮住对话区，文件预览最小宽度保持。官方在线基线已通过。
