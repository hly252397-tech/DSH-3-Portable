# 重启入口恢复

2026-09-12。用户报告左侧栏重启按钮一直未出现。

根因已在真实 Profile/Loader 页面复现：旧客户端使用 Object.assign 向 SVGSVGElement.viewBox 等只读属性赋值，MutationObserver 回调反复抛错，按钮未插入。旧逻辑还存在只观察后续变化、插入后断开观察而无法跟随后续侧栏重建的问题。

修复范围仅本地 dsh-restart-button 客户端。入口改用当前 Codex UI 1.1.2 已声明的 sidebar.footer.action 插槽；SVG 由 React 属性渲染。通过既有 dshDesktopShell.action('app-restart') 调用桌面桥接及主进程 requestAppRestart，不修改重启、进程、更新事务实现。首次点击确认、再次点击执行，错误可见。纯桌面功能在无桥接浏览器中不显示。

开发前对齐：前端与 UI 待验证；后端保留既有 IPC 权限与优雅关闭实现，本轮不触发用户正在使用的桌面重启。官方在线基线核对通过，HEAD c291e7961a515f6d7af9304e7fd1d257929aef26。生命周期经 ctx.slots 注册及 React effect 清理，不涉及模型输入或持久数据。
