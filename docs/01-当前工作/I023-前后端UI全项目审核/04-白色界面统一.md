# 白色界面统一

日期：2026-09-08。用户要求：截图中的界面统一白色。

## 范围与实现

- 左侧导航原先由 `local/dsh-codex-ui/dist/client.js` 固定为 `#eef7f5`，独立于主内容底色。改为消费官方 `--dsw-alias-bg-base`，白色作为缺省；悬停改为中性浅灰。
- `assets/theme.css` 的浅色 Qoder 画布、侧栏及布局容器使用统一白色；通过 body 上的官方 sidebar token 连接主界面底色。边框、选中态、按钮、遮罩和悬停仍使用各自语义变量。
- `src/desktop-theme.ts` 的浅色原生窗口背景统一为白色，覆盖标题栏、设置、外壳、快捷键；保持与 CSS 白色背景一致，减少窗口加载时的灰色闪烁。
- 此变更调整浅色配色，不删除深色主题和切换能力，不改用户会话、知识库或数据库；上一轮移除的模式切换、筛选和底部快捷入口继续保持下线。

## 三项对齐

| 层级 | 对应关系 | 结论 |
| --- | --- | --- |
| 用户入口 | 主界面、设置 → 通用设置 → 浅色、设置 → 侧边卡片、桌面外观设置 | 沿用已有入口 |
| 前端 | Codex 侧栏样式 → 官方主题 token；桌面 theme.css 与原生背景调色板 | 统一浅色背景，保留交互状态 |
| 后端 | ui-theme 设置及现有桌面主题同步链路 | 无接口或数据契约变更；本次颜色修改不新增后端 |
