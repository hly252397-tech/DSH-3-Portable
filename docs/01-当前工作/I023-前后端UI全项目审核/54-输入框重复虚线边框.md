# 输入框重复虚线边框

问题是未选工作区的原生cardWorkspaceTrigger通过::after的SVG遮罩画22px圆角虚线（inset:-1px），便携ROUNDED_PANEL_CSS又给实体卡加1px实线/首页10px圆角；证据是当前alpha.2的InputBar样式与运行时CSS，截图圆角位置正好分叉；下一步仅在已定制卡片上去掉该装饰伪元素，保留实体边框及原点击/键盘事件。

影响预判：只改sidebar-spaces的ROUNDED_PANEL_CSS及生成bundle，不改第三方运行时或React状态。最危险回归是失去未选工作区入口/键盘反馈；不删除cardWorkspaceTrigger类、不改aria/禁用条件，新增同一实体边框的hover/focus-within颜色。普通可输入卡、上传拖拽提示不匹配此规则。入口映射：原卡片onClick/onWorkspaceKeyDown→onRequestWorkspace→原工作区选择器，无后端新增接口、无设置写入。

当前已选工作区，实机普通卡无虚线；负对照采用真实卡临时添加官方cardWorkspaceTrigger类（只验证CSS，不冒充原生未选状态交互），使用当前真实样式复现双线并恢复。需另外测试原工作区选择器可打开、正常输入和聚焦不变。证据与结果待补。
