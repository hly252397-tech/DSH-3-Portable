# 浏览器卡片替换

日期：2026-09-08。用户要求：将侧边卡片中的浏览器替换为顶部工具栏对应的桌面浏览器，移除原实现。

## 实现与三项对齐

| 用户入口 | 前端调用 | 桌面处理与反馈 |
| --- | --- | --- |
| 侧边栏 → 新建标签页 → 浏览器 | `createNativeBrowserView` → `dshDesktopShell.browserPanel.show` | 同一组原生浏览器标签页显示在卡片内部，包含地址栏、收藏、资料、下载与更多菜单 |
| 顶部浏览器按钮 | 现有 `browser.toggle` | 复用同一浏览器状态、收藏和历史，不创建第二套 iframe 浏览器 |
| 卡片折叠、卸载或切换 | 带实例标识的 hide；旧实例请求不影响新实例 | 隐藏原生视图，保留浏览器标签页和资料 |
| 卡片缩放与移动 | 持续报告 DOM 边界，主进程校验并布局 | 原生工具栏和网页跟随卡片位置 |
| 设置、菜单与弹窗 | 现有设置遮挡信号及相交浮层检测 | 原生网页暂时隐藏，弹窗关闭后恢复 |
| 浏览器功能设置 | 保留 HTTP/HTTPS 链接接管开关 | 链接送到原生浏览器；删除 iframe 沙箱及回环白名单控件 |

维护位置为 `Data/DSH/profiles/web/local/dsh-better-sidebar/`，仍采用官方 Profile/Loader 注册。`portable/browser-view.js` 为卡片组件源文件，`scripts/build-native-browser-card.mjs` 将其写入插件客户端产物。插件保持 `0.18.0-alpha.0`，包内另有本地定制标记；Profile 依赖指向本地维护副本。

原 `BrowserView` 的 iframe、嵌入探测路由 `browser.probe` 与客户端调用已移除。旧偏好字段保留用于读取历史配置，已无可操作控件和执行路径；不删除用户会话、收藏及浏览数据。模型侧 `sidebar_open` 的浏览器说明同步改为共用原生桌面浏览器。

桥接采用版本检查和实例归属校验，过旧桌面显示更新提示及重试按钮。URL 输入仅接受 HTTP(S)，拒绝桌面内部协议、带用户名密码的 URL 及当前 DSH 站点，避免把应用控制页面当作普通网页打开。卡片不足 280 × 240 时显示尺寸提示并隐藏原生视图，扩大后恢复。

浏览器卡片只保留一个实例。既有卡片接收新 URL 时更新导航标识，避免通用卡片去重逻辑仅聚焦旧页；连续点击不同链接以及重复点击同一链接均已通过真实事件链验证。

## 同期侧栏更新处理

审核中发现正式 Profile 的 Codex 侧栏已从 `0.2.101` 更新为 `0.2.113`，入口产物由 `dist/client.js` 改为 `lib/client.js`。保留新版，将已有白色背景、样式归属、宽度拖柄隐藏、批量归档、搜索文案和独立扩展入口修改迁移到新产物，所有相关测试改为读取实际新路径。旧产物已移到本轮证据目录。

正式 Profile 的 CLI 本地安装步骤实际写入了本地浏览器包与锁文件，但随后因已存在的 `dsh-codex-ui@0.2.113` 和 `lucide-react@1.42.0` 未满足 24 小时发布龄策略而返回失败并回滚 manifest。没有降低发布龄策略，也没有将该步骤记录成安装成功；仅修复 manifest 与已经写入的本地浏览器依赖/锁文件一致。该 Profile 的后续依赖安装仍须满足原有策略。
