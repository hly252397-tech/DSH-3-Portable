## 修复与开发态验证

- 删除 `assets/shell.html` 顶部按钮以及 bootstrap、状态刷新、点击监听中的关联引用；右侧浏览器卡片和浏览器数据不变。
- `assets/browser-workspace.css` 将隐藏快照选择器改为 `.browser img.browser-page-snapshot[hidden]`，保证优先级高于显示规则。更多菜单打开仍使用现有快照，关闭后彻底隐藏；不再出现顶部 14 px 白条。
- `src/browser-panel-layout.ts` 将 CSS 矩形乘以发送方实际缩放系数后转换成 DIP，并继续执行有限数、最小尺寸及视口裁剪校验。主进程从 `event.sender.getZoomFactor()` 取值，不信任页面自报比例，也不混用包含屏幕 DPI 的 `devicePixelRatio`。
- 新卡片在首次有效坐标到达前不显示旧位置；尺寸无效时隐藏原生表面，避免沿用过时坐标覆盖邻近界面。

类型检查通过，全量测试 388 项：387 通过、0 失败、1 跳过。新增缩放坐标换算与非法比例回归，既有入口检查覆盖实际删除的按钮。日志：`artifacts/browser-entry-layout-20260908/tests.log`。
