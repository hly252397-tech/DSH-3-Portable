# 侧栏框选入口移除

日期：2026-09-08。依据用户最新截图及“移除红框内的功能”要求，本记录覆盖此前恢复这些侧栏入口的结论。

## 下线范围与对应关系

| 用户入口 | 前端变更 | 后端与保留入口 | 结果 |
| --- | --- | --- | --- |
| 左侧顶部“编程 / 通用” | 删除工作模式侧栏挂载、事件与样式 | 设置 → 模式配置仍经 settingsScope 保存默认模式；已有会话记录保留 | 该侧栏入口下线 |
| “全部 / 编程 / 通用”筛选 | 删除任务分类请求、观察器与过滤样式；加载时清理 localStorage 的旧筛选值、body 过滤属性及会话行分类属性 | 分类存储和只读接口作为已有会话元数据兼容能力保留，不再由侧栏发起请求 | 已有会话行保留，不因旧筛选隐藏 |
| 左侧底部“知识与数据”图标 | 删除 sidebar.footer.action 注册及专用文案 | 知识中心、数据库等继续由右侧卡片访问，后端数据与接口保留 | 快捷入口下线 |

“侧边卡片”设置、DSH-better-sidebar 插件及其扩展卡片保持启用。没有修改用户知识库、数据库、会话或模式设置。

## 变更与验证

- 修改两个本地插件客户端，重新生成 sidebar-spaces 客户端；同步正式 Profile 已安装客户端并核对 SHA-256。此次未改 src/，不涉及桌面重新打包。
- 官方在线基线核验通过：内置 0.1.2-alpha.3，审查基线 0.1.3-alpha.2，官方提交 c389f96bf3a9b6807cb71ed6bdad5849be0df6d8。
- 类型检查通过；全量测试 **383 项：382 通过、0 失败、1 跳过**。将 8 项要求已下线控件存在的旧用例替换为 1 项旧状态清理行为测试，因此比上一轮 390 项减少 7 项，并非跳过失败测试。宿主、设置和卡片生命周期测试保留。
- 使用实际 0.1.2-alpha.5 运行时、真实 Profile/Loader 和 Electron，在隔离数据目录验证：两组控件不存在、底部快捷入口不存在；预置旧筛选后重载能清理；设置可打开；侧边卡片中知识中心、数据库、Inventor、任务管理仍在；任务管理内部功能设置可打开并关闭。
- 已查看隔离环境截图，顶部与底部移除后没有遗留空白控件。未强制退出用户桌面，当前已打开页面需要重新加载或正常重启以使用更新后的客户端。
