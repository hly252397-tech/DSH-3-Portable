## 第2轮：第一次真实回归失败后修正

第1轮通过原生文件树读取、卡片入口打开及卡片预览，但“原生重新打开”仍测出 native=true/cards=true。只包裹 layout.openRightbar 不能覆盖官方控制器内部路径/绑定时序，撤销此包装方案。

改为观察根渲染提交后读取公开 native.isExpanded()，不按 CSS 类推断原生状态；同帧合并检查，只有确实双开才调用 cards.setPanelOpen(false)。卡片订阅仍在从关闭转打开时调用原生 toggleExpanded。observer、requestAnimationFrame 和订阅都随 ctx.effect 清理，旧运行时没有 sidebarRight 时可选注入不影响其他能力。实际文件范围不变。

## 第3轮：真实按钮命中发现遮挡

第2轮双向状态互斥已通过，但原生“收起右侧边栏”实际点击被卡片固定开关遮挡。修正：原生展开面板内 data-sidebar-right-toggle 右侧预留76px，给两枚卡片开关让位，保留所有按钮及命中范围；观察器限定官方稳定 data-sidebar-right-open/panel 属性及子树挂载变更。继续实测，未强制点击绕过问题。

测试环境记录：一次重试因原生 session surface 尚未挂载失败，QA 改为等待 rightbar.session 附着；之后真实后端在外部重启中由52951变为54153，终止仅本任务隔离 QA Electron，重新发现端口后续测；没有结束用户桌面或发送消息。此类 readiness/端口错误不以改产品逻辑掩盖。
