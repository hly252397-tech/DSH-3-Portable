# 设置导航图标去重

状态：图标去重已部署到现役并通过范围内验收；不代表所有设置功能已无缺陷。模型自我感知增强按用户“先做这个”暂缓，尚未改认知插件。

问题是设置导航不同功能复用图标；证据是当前 Codex UI 的 sectionIcon 将 plugin 全映射滑杆、connector/mcp 全映射链条、未识别项默认 Box，实图可见三组重复；下一步是在既有 ui-tweaks 定制层给五个重复入口设独立语义图标，保留原按钮、文本、路由与事件。

## GCC

1. 模块：本地 dsh-ui-tweaks 客户端，代码地图的 UI 定制层。
2. 职责：样式/装饰图标，不承担设置业务。
3. 上游：Codex UI 的 SettingsPage / sectionIcon，渲染原 button+svg+span。
4. 下游：只标注导航按钮并用 CSS currentColor mask 显示装饰图标，不调用后端。
5. 调用方：插件 apply → 可撤销图标效果；仅 .dcu-settings-nav .dcu-settings-link。
6. 公共能力：ctx.effect、MutationObserver、requestAnimationFrame、原主题色。
7. 相似实现：原 Codex UI observeSettingsNavIcons；不改其 npm 产物，以便更新后保留定制。
8. 复用：原 ui-tweaks 客户端容器、原点击路由、原16px布局。
9. 接口：无 API/Schema 变化；精确中英文标签匹配，未知项不碰。
10. 约束：不替换原 DOM、不增加定时器/重启逻辑；每次标记有幂等判断，卸载移除本轮样式/标记。
11. 影响：设置导航图标/搜索/重开/主题与宽窄；对话输入条仅作为间接不变回归。
12. 不动：官方包、桌面源码/槽、MCP 后端、模型认知、其他入口及用户配置。
