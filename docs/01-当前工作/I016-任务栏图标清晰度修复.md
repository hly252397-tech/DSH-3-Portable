# I016 任务栏图标清晰度修复

日期：2026-09-05。范围仅为窗口/任务栏图标生成链，不重绘鲸鱼、不修改托盘、通知、安装器或页面图标。

## 根因与修复

实际正式窗口属于桌面 PID 41396，槽 `1.0.46-local-9ce60671cf7bd302`。其 `resources/taskbar.png` 与仓库 `assets/icons/taskbar.png` 相同，SHA256 为 `70B1BB9BD8C50EE8A5AD5834EEDF7DB5EEDF91DB7F7E5BC80B44B19287A4C4AF`，源图是 512 × 512。

旧 `resolveWindowIconImage()` 把 16、20、24、32、40、48、64、256 各尺寸全部以 `scaleFactor: 1` 加入同一 NativeImage。实际 Electron 44.0.0 原生实验中 `getSize()` 返回 16 × 16，后续大尺寸不是有效的独立倍率。Windows 再显示此低分辨率位图，边缘明显模糊。

修复移除重复倍率循环，保留既有裁边后的 456 × 456 高清位图及缓存。保持第一版鲸鱼素材和留白裁剪不变。没有生成替代品牌图案。

一手依据：[Electron NativeImage](https://www.electronjs.org/docs/latest/api/native-image) 的 representation 按倍率注册；[实际版本 GetHICON 实现](https://github.com/electron/electron/blob/v44.0.0/shell/common/api/electron_api_native_image.cc) 使用 `image_.AsBitmap()` 创建 Windows HICON。
