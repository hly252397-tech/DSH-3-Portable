## 证据链

1. **运行期确证重启**：GUI 端口由 50984 变为 52049（应用被回收重启）。
2. **自愈记录（决定性）**：`profiles/web/.dsh-recovery/quarantined-bundles.json` 在本地 12:18:40 / 12:19:55 各新增一条 `source: preflight`、`reason: 插件 package.json 不存在。` 的记录：
   - `@deepseek-ai/dsh-experimental-agent-team-profile`（智能体团队）
   - `@deepseek-ai/dsh-experimental-auto-review`（自动授权审查）
   同时 `profiles/web/package.json` 被重写（12:19:55），这两项已从 `dsh.profile.bundles` 摘除 —— 所以重启后开关必然是关的。
3. **隔离前 manifest 备份**：`.dsh-recovery/manifest-backups/2026-09-28T04-19-55-390Z-…-@deepseek-ai_dsh-experimental-auto-review.json` 里该包**确实在 bundles、不在 dependencies**，与官方实现一致。
4. **官方语义（源码）**：
   - `dsh-plugin-manager` 的 `selectBundle(name, enabled)` 只写 `dsh.profile.bundles`（**从不写 dependencies**），随后 `this.reload(...)` 重载运行时 —— 这就是用户看到的「重启」。
   - 它用 `bundleManifest(name, profileDir, installAnchor)` → `resolveBundleDir('dsh', name, anchor, dir)` 解析包：**唯一安装锚点 + profile 两处都找**。
5. **三个包的实际位置**：`@deepseek-ai/dsh-experimental-{agent-team-profile,auto-review,voice-input-bundle}` 都只在运行时安装目录 `Data/Runtime/Harness/slots/<slot>/node_modules/@deepseek-ai/` 里，profile 的 `node_modules` 里没有（这是官方 bundle 的正常形态）。
6. **便携侧预检过严（根因）**：`src/profile-bundle-health.ts` 的 `inspectProfileBundle` 只看 `<profile>/node_modules/<pkg>/package.json`，与官方「安装锚点 + profile」不一致 → 判定「插件 package.json 不存在」→ 预检隔离并把包从 bundles 摘掉 → 开关被打回。
   - 对照：`plugin-seed.ts` 的 `isResolvableProfileBundle(profileDir, name, extraDirs)` 本来就按 `[profileDir, ...extraDirs]` 判定，**同仓两套判定不一致**；`pruneMissingProfileBundles` 对 `@deepseek-ai/*` 一律放行（`isDeepSeekOfficialPackage` 前缀判定），所以真凶只有预检这一处。

## 修复

把预检解析与官方对齐，并把 `extraDirs`（= 运行时安装目录）串到所有相关点：

- `src/profile-bundle-health.ts`：`inspectProfileBundle(profileDir, packageName, extraDirs = [])`，新增 `resolveBundlePackageRoot` / `resolveDependencyManifest`，按 `[profileDir, ...extraDirs]` 解析；缺包才报「插件 package.json 不存在」。
- `src/profile-quarantine.ts`：`activeQuarantinedProfileBundles(profileDir, extraDirs)`、`quarantineProfileBundle(..., { extraDirs })` 的指纹与健康判定同样带 extraDirs（旧误隔离记录会在下次启动被标记 `resolvedAt`）。
- `src/profile-repair.ts`：预检隔离与启动期隔离都传 `extraDirs`。
- `src/plugin-seed.ts`：`reconcileProfileBundles(profileDir, packageNames?, extraDirs)` 及其调用点（`finalizeProfileBundlesAfterInstall`、seed 收尾）传 extraDirs。
- `src/main.ts`：运行时隔离传 `lastSeedOptions.desktopRuntimeDir`。
