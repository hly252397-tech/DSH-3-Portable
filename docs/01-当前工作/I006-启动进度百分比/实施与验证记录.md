# I006 启动进度百分比 — 实施与验证记录

## 目标

在桌面启动页的进度环中央显示可读的整数百分比，并让圆环填充与百分比同步。进度必须来自已提交的启动阶段，不使用定时器伪造连续增长。

## 决策

- 使用 `5% → 10% → 15% → 45% → 50% → 70% → 74% → 80% → 84% → 88% → 90% → 97% → 100%` 的阶段里程碑。
- 解压协议目前只提供阶段开始、完成和跳过事件，因此百分比表达“已完成启动阶段权重”，不冒充字节级解压进度。
- 主进程使用单调推进函数，晚到事件不能让百分比回退；页面使用 revision 拒绝过期状态覆盖。
- `100%` 只在主窗口导航完成后写入主进程状态。启动页最后可见状态为 `97%`，随后切换到已加载的主界面，避免提前显示完成。
- 非启动场景复用启动页但未提供百分比时隐藏进度环，避免错误页出现误导性的 `0%`。

## 兼容性审查

- 本改动属于 Electron 桌面宿主，不修改 DeepSeek Harness 运行时、Profile、Cordis 插件树或模型可见输入。
- 在线官方基线核对通过：内置实现基线 `0.1.2-alpha.3`，官方审查基线 `0.1.2-alpha.5@49a606bc5b5934603f22a26957a07dc799ab0291`。
- 进度元素提供 `role="progressbar"`、`aria-valuemin`、`aria-valuemax` 和动态 `aria-valuenow`。
