## 0. 执行环境与权限现实（opencode 必读，先读这一节）

你的 bash 权限由 `opencode.json` 决定。**allow** 的前缀：
`git` `pnpm` `node` `rg` `grep` `find` `ls` `dir` `cat` `head` `tail` `wc` `stat` `diff` `sha256sum` `sed -n` `mkdir` `cp` `tar` `robocopy` `powershell`。
其余一律 **ask**（非交互 `opencode run` 下会卡死/失败）。因此：

- **禁止** `rm` / `mv` / `curl` / `wget` / 任何未列出的命令。需要"删除"时用 `edit`/`write` 工具重写文件，或用 `robocopy /MIR`（allow）做镜像同步。
- **禁止**裸 `node` 跑门禁。`node *` 匹配的是**系统 node**，而 AGENTS.md 强制用内置 node（版本门禁）。内置 node 路径 `App/resources/node/node.exe` 不以 `node` 开头，会被判 ask。**正确做法：用 powershell 包一层**（`powershell *` 是 allow）：
  ```
  powershell -NoProfile -Command "& 'G:\DSH-3-Portable\App\resources\node\node.exe' node_modules/typescript/bin/tsc"
  powershell -NoProfile -Command "& 'G:\DSH-3-Portable\App\resources\node\node.exe' --test dist/test/work-mode.test.js"
  ```
  注意：powershell 命令里若含 `$_`、`[Math]::` 等，在 Git Bash 下会被 bash 展开——本任务书给的命令不含这些，照抄即可。
- 文件读写**一律用你的 read/write/edit 工具**，不要 `cat >` / `echo >`。
- **字节一致核验只用单条 `git diff --no-index <A> <B>`**（git 在 allow，无输出=一致）。**不要**用 `diff -q`，更**不要**把多条命令用 `;`/`&&` 串成复合命令。

### 0.1 工具现实（上一轮就栽在这两条，务必遵守）

1. **`Data/` 被 gitignore，你的 `glob`/`find` 会跳过它**，对 `Data/DSH/profiles/**` 下任何路径返回 **0 matches**（上一轮实测：`glob local/dsh-sidebar-spaces/lib/*.js` → 0，但文件确实存在）。**禁止用 glob/find 去"发现/核对" Data/ 下的文件布局**——本任务书 §3 已给出全部精确路径与行号（Qoder 已逐一核实），直接用 **read 工具按绝对/相对路径打开**即可（read 对 Data/ 有效，上一轮 `read client.js`/`read sidebar-spaces` 都成功）。需要确认结构就 read，不要 glob。
2. **你的 bash 在 Windows 上走 PowerShell，权限按"单条命令前缀"匹配 allow 列表**。一旦命令里含未授权 token（如 `echo`）或用 `;`/`&&` 串接，整条会被判 ask 并 **auto-reject**（上一轮 `dir A; echo ---; dir B` 因 `echo` 未授权被整体拒绝，导致任务中止）。所以：
   - **一次只跑一条命令**，绝不 `;`/`&&` 串接，绝不加 `echo` 分隔。
   - **禁止** `echo`/`rm`/`mv`/`curl`/`wget`/裸 `dir`（不在 allow 或易触发复合拒绝）。列目录用 `ls <path>`（allow）或干脆用 read 工具。
   - **权限被 auto-reject 不是任务失败、不是 §10 的停止条件**：换一条 allow 命令，或改用 read/write/edit 工具，继续干。绝不因为一次拒绝就 disposing/结束任务。
3. 门禁与核验命令（§7）都已写成**单条、powershell 包内置 node** 或 **单条 git** 的形式，照抄，不要改写、不要串接。
- **不要碰** `App/`、`App/resources/app.asar`、`Data/Updates/Desktop/slots/`、任何打包/部署脚本。本轮**不重新打包、不覆盖 App**（只动 `Data/DSH/profiles/**` 运行时数据，不触发打包）。

## 4. 架构决策（Qoder 已定，照此实施）

因为 §3.1 的"行不暴露 sessionId"是硬约束，唯一既**稳健**又**留在插件/profile 层、不重新打包**的路线是：

> **给 codex-ui 的 `SessionRow` 根 div 补一个 `data-session-id` 属性（enabler），再由 work-mode 客户端按该属性打标 + CSS 过滤。**

这是对一个 vendored 社区插件 dist 包的**单属性**外科式补丁。取舍已记录在 §10，核实者知情。

### 4.1 enabler：codex-ui SessionRow 暴露 sessionId

在 `SessionRow` 根 div（`dist/client.js:539` 的 `jsxs("div", { ... })` props 对象）里**新增一个属性**：
```js
"data-session-id": id,
```
- 只加这一行，放在 `className` 之后、`role` 之前即可（位置不敏感，只要在同一个 props 对象内）。
- `id` 在该作用域已存在（函数形参，`:538`）。3 处渲染都走同一组件，改一处即全覆盖。
- **两份拷贝都要改**：`local/dsh-codex-ui/dist/client.js` 与 `node_modules/@michengai/dsh-codex-ui/dist/client.js`，改完 `diff -q` 必须无输出。
- 不许顺手"美化"或重排 bundle 其它部分——只加这一个属性，把 diff 面收到最小（降低 codex-ui 同步时的冲突面）。

### 4.2 host：work-mode 暴露只读 sessionModes 路由

在 `local/dsh-work-mode/lib/index.js`：
1. `export const inject` 增加 `'webServer'`（→ `['sessions','settings','storageDomain','webServer']`）。`webRuntime` 仅在你需要 `trustedHosts` 时再加；sidebar-spaces 用 `ctx.webRuntime.trustedHosts`，若你改用更简单的同源校验可不注入 webRuntime（少注入少 PENDING 风险）。**默认：注入 `webServer`，自校验用 origin 同源（照 sidebar-spaces `:135-136` 的 `origin === 'http://'+host` 判定），不注入 webRuntime。**
2. 用 `ctx.effect(() => ctx.webServer.register({ kind:'exact', path:'/work-mode/api/session-modes', handler }), 'dsh-work-mode: session-modes route')` 注册只读 GET 路由（effect 注册保证自动清理，**不要**手动 removeListener）。
3. handler：
   - 仅允许 GET；否则 405。
   - 同源自校验（origin/host）；不可信 403。照抄 sidebar-spaces `writeJson` 形状回 `{ ok:true, value:{ sessionModes } }`。
   - `sessionModes` 直接取宿主内存 Map 的快照：`Object.fromEntries(sessionModes)`（apply 作用域里已有该 Map）。**只读**，不在此路由写盘。
4. 路由是**只读视图通道**，不触碰档位权威（档位仍只由 settings + session/created 写）。

> 备选：若你核实 `ctx.connection.rpc.handle` 在 alpha.3+alpha.5 均存在且客户端可调，可用 rpc 取代 HTTP；但**默认 webServer**，因为它在本仓库已被 sidebar-spaces 实证。

### 4.3 client：work-mode 拉映射 + 打标 + CSS 过滤

在 `local/dsh-work-mode/lib/client.js`：
1. **拉映射**：启动时 `fetch('/work-mode/api/session-modes', { ... 同源 })` 取 `{ sessionId: mode }`。失败/不可用时**优雅降级**：过滤入口隐藏或置灰，会话列表保持原样（绝不因拉取失败而报错或遮挡列表）。可在档位快照变化时按需重拉（订阅 revision）。
2. **打标**：常驻 `MutationObserver` 观察侧栏会话列表容器，对每个 `.dcu-wb-session[data-session-id]` 行，按映射写入 `data-session-mode="coding"|"general"`（无记录的按 I021 语义视作 `coding`）。**幂等**：已打标且值正确的行跳过；React 重渲染带走属性后补打。照 I021 `ensureMounted` 的幂等补挂思路。
   - 观察目标容器：用 codex-ui 侧栏的稳定祖先（如 `.dcu-expanded-shell` 或会话列表的滚动容器）。**不要**观察整个 `document.body` 之外的东西；若必须观察 body，注意性能（I021 已观察 body，可复用同一观察器或并列一个）。
3. **过滤入口**：渲染"全部／编程／通用"三态分段控件。
   - **挂载位置遵守头部零改动铁律**：不得进 `.dcu-head`。作为 I021 开关容器 `.dwm-switch` 的**兄弟节点**（同样在 `.dcu-expanded-shell` 内、头部之后），或紧贴会话列表上方。**禁止**对 `.dcu-head` 写任何覆盖、禁止 grid-area/grid-template/height 改动。
   - 过滤态是**本地视图偏好**：存 `localStorage`（键名带插件前缀，如 `dsh-work-mode:filter`），**不写宿主 settings**，不触发 `scope.set`。
4. **过滤实现走 CSS，不逐行改 inline style**（避免和 React 抢 style）：
   - 在 `body` 上写 `data-dsh-work-mode-filter="all"|"coding"|"general"`。
   - 样式表（注入到 `style[data-plugin="dsh-work-mode"]`，沿用 I021 的 `ensureStylesheet`）加：
     ```css
     body[data-dsh-work-mode-filter="coding"] .dcu-wb-session[data-session-mode="general"]{display:none!important}
     body[data-dsh-work-mode-filter="general"] .dcu-wb-session[data-session-mode="coding"]{display:none!important}
     ```
   - `all`（默认）不加任何隐藏规则。
5. **文案**走本地化字典（zh/en），与 I021 同一套机制；不硬编码中文/英文字符串到逻辑里。
6. **清理**：effect disposer 里断开新增的 MutationObserver、移除新增 body 属性、移除过滤入口节点。不得泄漏。

## 6. 坑清单（逐条遵守，都是本仓库踩过的）

1. **storage domain 单元名下划线**：`work_mode` 不能写成 `work-mode`（连字符抛 `invalid unit name`）。settings 命名空间反过来用连字符 `work-mode`。两者规则不同，别混。
2. **头部零改动铁律**：任何对 `.dcu-head` 的覆盖（改列、加行、放高、grid-area、grid-template、height）都会连锁破坏 logo 尺寸与右侧图标定位。过滤入口**不得**进头部，作兄弟节点。
3. **兄弟节点幂等挂载**：React 重渲染会带走节点，MutationObserver 常驻 + 幂等补挂（`parentElement`/`previousElementSibling` 判定），照 I021 `ensureMounted`。
4. **inject 只写存在的服务**：`webServer` 已由 sidebar-spaces 证明存在；不确定的服务（如 `webRuntime`、`connection`）**不要**写进 inject，PENDING 会启动失败。默认只加 `webServer`。
5. **命名导出形态**：work-mode 是 `name`+`inject`+`apply` 命名导出，模块级 `export const inject` 即权威，cordis.patch.yml **只**写 `id`+`name`，不要在 patch 里写 inject。
6. **双拷贝必须字节一致**：work-mode（local ↔ `node_modules/dsh-work-mode`）、codex-ui（local ↔ `node_modules/@michengai/dsh-codex-ui`）。改完 `diff -q` 核验。宿主读 node_modules 那份，漏改=改了个寂寞。
7. **无乐观 UI**：档位高亮只由宿主提交后快照驱动（I021 既定）。过滤态是本地视图，不写宿主。
8. **setSource 是 thunk**：`installSection` 的 `hooks.setSource` 收到的是函数，读时再取值（I021 既定，别改坏）。
9. **路由只读 + 同源校验 + effect 清理**：webServer 路由必须自校验同源（照 sidebar-spaces），只读 GET，effect 注册自动清理，不手动 removeListener。
10. **CSS 过滤而非 inline style**：用 `body[data-dsh-work-mode-filter]` + 行 `data-session-mode` 选择器隐藏，别逐行写 `style.display`（会和 React 抢）。
11. **降级不致命**：fetch 失败时列表保持原样、过滤入口隐藏/置灰，**绝不**抛错遮挡列表或触发 fail-loud（alpha.5 桌面会硬退出）。
12. **本地化字典拥有文案**：新增"全部/编程/通用"过滤文案走字典 zh/en，不硬编码。
13. **powershell 跑内置 node**：门禁命令必须 `powershell -NoProfile -Command "& '<abs>\App\resources\node\node.exe' ..."`，不要裸 `node`（系统 node 违版本门禁），也不要直接 `./App/...node.exe`（会被判 ask）。
14. **cwd 别泄漏**：跑测试前确保在仓库根 `G:/DSH-3-Portable`（在 profile 子目录跑会破坏 `process.cwd()` 相对路径）。
