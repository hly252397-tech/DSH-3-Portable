## 3. 架构决策与取舍

**问题**：§3.1 证实 codex-ui `SessionRow` 根 div 不把 sessionId 写进 DOM 属性，纯 DOM 覆盖层无法把"会话行"稳定映射回 sessionId（分组/置顶/归档/排序/虚拟化都会破坏行序）。

**决策**：对 vendored codex-ui dist 包做**单属性外科式补丁** —— 在 `SessionRow` 根 div props 加 `"data-session-id": id,`（enabler），再由 work-mode 客户端按该属性打标 + CSS 过滤。

**取舍记录**（任务书 §10）：
- 代价：将来同步/升级 codex-ui 时该补丁会被覆盖，需重打（已在 I021 台账登记补丁点，见 §8）。
- 备选"slots 整列替换"过大且 fail-loud 风险高 → 否决。
- 备选"行序/标题猜映射"脆弱 → 否决。
- 若用户不愿补丁第三方 bundle，则按档过滤需推迟到 codex-ui 上游支持 `data-session-id` 之后 —— 本轮唯一的架构取舍点。

**host 侧**：暴露只读路由 `/work-mode/api/session-modes`（`ctx.webServer.register`，kind `exact`，GET 只读），直接返回内存 `sessionModes` Map 快照（`Object.fromEntries`），**不写盘、不触碰档位权威**。同源校验照 `dsh-sidebar-spaces` 的形状：origin 缺失视为同源、origin 与 `http://`+host 不符拒绝（403）。effect 注册自动清理，不手动 removeListener。

**client 侧**：启动 fetch 映射 → MutationObserver 给 `.dcu-wb-session[data-session-id]` 行写 `data-session-mode`（无记录按编程档）→ 过滤入口三态控件挂 `.dcu-expanded-shell` 内头部之后（`.dwm-switch` 兄弟位，**不进 `.dcu-head`**）→ 点选写 `body[data-dsh-work-mode-filter]` + CSS 隐藏 + localStorage 持久 → fetch 失败优雅降级（入口不挂、列表不动、不抛错）→ disposer 断开观察器/移除节点/移除 body 属性。

## 4. 实施要点

- **codex-ui enabler**：只加 `"data-session-id": id,` 一个属性（`className` 之后、`role` 之前），未动 bundle 其它部分，diff 面最小。
- **host 路由**：`ctx.effect(() => ctx.webServer.register({kind:'exact', path:'/work-mode/api/session-modes', handler}), 'dsh-work-mode: session-modes route')`，handler 只允许 GET（否则 405）、同源校验（不可信 403）、回 `{ok:true, value:{sessionModes:Object.fromEntries(sessionModes)}}`。
- **client 过滤**：
  - 打标函数 `paintRows`：`state.ready` 后才动手，行 `data-session-mode` 已正确则跳过（幂等）。
  - 过滤入口 `ensureMounted`：`state.ready` 前不挂；`root.parentElement !== parent || root.previousElementSibling !== host` 时幂等补位。
  - 过滤实现走 CSS（`body[data-dsh-work-mode-filter="coding"] .dcu-wb-session[data-session-mode="general"]{display:none!important}` 等），不逐行改 inline style。
  - 过滤态存 `localStorage['dsh-work-mode:filter']`，启动时 `readStoredFilter` 恢复。
  - 文案走本地化字典（zh/en 的 `filter.all/coding/general/aria`）。
  - disposer：`observer.disconnect()` + 移除节点 + `document.body.removeAttribute('data-dsh-work-mode-filter')`。
- **单测**（`test/work-mode.test.ts`，node:test，沿用现有 mock 风格）：
  - host：`inject` 含 `webServer`；路由 handler 对不可信来源回 403、非 GET 回 405、可信 GET 回 `{ok:true,value:{sessionModes}}` 且只读（不改 Map、不额外落盘）。
  - client：打标把 `.dcu-wb-session[data-session-id]` 按映射写 `data-session-mode`、无记录视作 coding；幂等（重复观察不重复写）；过滤态写 `body[data-dsh-work-mode-filter]` 且存 localStorage；fetch 失败降级（不抛、列表不动、入口不挂）；disposer 清理观察器/属性/节点；样式表含过滤规则且不含 `.dcu-head{`/grid-area/grid-template。
