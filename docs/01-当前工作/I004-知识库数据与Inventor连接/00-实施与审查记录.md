# I004：知识库、数据可视化与 Inventor 2027 连接

## 目标

在不修改 DeepSeek Harness 官方运行时、桌面主进程和现有数据格式的前提下，升级 `dsh-sidebar-spaces`：

1. 知识库提供知识条目与数据库记录的跨库搜索。
2. 数据库图表从单字段分布升级为可配置的数据分析视图。
3. 增加 Autodesk Inventor 2027 的本机检测与显式启动入口。

## 决策与边界

- 继续通过 `dsh-better-sidebar` 的公开 `registerTab` API 注册页面，不注入或修改官方客户端 DOM。
- “全局搜索”的当前边界是本插件拥有的知识条目和数据库记录。插件没有会话全文或磁盘全文索引服务，因此不把结果描述成整机搜索。
- 保持 localStorage schema 为 `1`，不迁移、不清空已有数据；写入仍保留 `.prev` 快照。
- Inventor 连接只检测和启动本机 2027 桌面程序。不会读取、修改或保存模型；后续 CAD 自动化应通过独立 COM/Add-In 能力层实现。
- Inventor 路由只接受同源 loopback 或 `webRuntime.trustedHosts` 请求，并拒绝跨站浏览器请求。启动子进程不经过 shell，且删除凭据形态环境变量。
- 本地插件目录与 Profile 的 `node_modules` 副本保持逐文件 SHA-256 一致。

## 实现摘要

- 跨库搜索：NFKC 归一化、多关键词 AND 匹配、标题/标签/正文加权、来源统计、数据库结果跳转与记录高亮、`Ctrl/Cmd+K` 聚焦。
- 可视化：总记录/已填/唯一值/完整率卡片，动态直方分桶，分类 Top N，数字字段合计/平均/最小/最大聚合，日期日/月趋势，双数值字段散点图，PNG 导出。
- Inventor：新增 `space-inventor-2027` 标签和 `/sidebar-spaces/api/inventor/{status,launch}` 两个宿主路由；默认从 Program Files 自动发现，也支持 `inventorExecutable` 配置。
- 生成方式：`lib/client.src.js` 的 ECharts 占位符替换为隔离 IIFE，输出 `lib/client.js`，避免 ECharts UMD 污染插件模块的 `module.exports`。
