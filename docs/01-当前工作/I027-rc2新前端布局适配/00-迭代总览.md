# I027 — rc.2 新前端布局适配与对话保护收口

## 1. 背景
运行时自动切换到 0.1.5-rc.2 后，`dsh-web-frontend` 全新 UI（模块哈希 `17p4l` 系列）上线：工作台标签条、标签菜单、分栏体系全部换新。便携主题此前对旧版类名的钳制部分失效，出现：①标签菜单（fixed 定位、JS 右对齐锚点）左缘伸进便携侧栏区；②对话内容被历史拖拽偏好裁切；③原生浏览器面板过宽。

## 2. 本轮修复（v1.0.62–v1.0.65）
1. 官方模型对齐：清除 `--dsh-chat-user-width` 历史偏好，恢复官方 `clamp(680px, 列宽×64%, 920px)` 响应式；对话列底线提到官方内容下限 680px。
2. 页面内面板钳制：`100vw − 1040px`、<1100px 隐藏。
3. 原生面板双路径保护：`capBrowserWorkspacePanelWidth`（viewport−900px）同时约束比例推算与页面报告 bounds；ratio 上限 0.48。
4. rc.2 标签菜单钳制：`[class*="_menu_17p4l"]` 左对齐到侧栏之外（260px），不再盖住侧栏。

## 3. 验证证据
- CDP 实机：容器 623px 时内容 623px、零裁切；面板 460/对话 508@1450 窗口；官方源码 `dsh-client-ui-conversation` clamp 模型核对。
- 门禁：431+ tests / 0 fail（本地 UI 基线另行登记）。

## 4. 遗留
- 标签菜单类名 `_menu_17p4l_444` 哈希随构建变化，已用前缀匹配；未来前端大版本需复核。
- UI 基线同批含并行会话 black-hole WIP 漂移，由该会话自行登记。

## 5. 吸收项落地（v1.0.66）

对照清单吸收项 1 落地：theme.css 新增负字距阶梯令牌（tight -0.02em / tighter -0.03em / display -0.0375em，参考 Linear DESIGN.md），settings/about/shortcuts 页面 h1 消费 。CDP 实机验证：settings h1 24px 字距 normal → -0.48px（精确 0.02em）。UI 基线已用实机证据重登记。
