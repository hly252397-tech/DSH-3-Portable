# 2026-10-01 回退警告胶囊 + Chrome 排版基线

## 起因

1.0.78+build.1 被回滚到 1.0.77，用户全程零提示。两条独立成因与四条修复见
[UI 定制维护契约](../03-技术架构/UI定制维护契约.md) 的 2026-10-01 节。本文件是本次
UI 基线记录的**变更记录**（`scripts/ui-baseline.mjs --record --note` 强制要求）。

## 本次纳入基线的 UI 改动

### 1. 黄色回退警告胶囊（本次修复，主角）

用户要求：提示"已被回滚到旧版本"，位置在顶栏重启按钮**左边**，黄色胶囊，两端半圆。

- `.rollback-capsule`：`#fadb14` 底 / `#3d2b00` 字 / `height:22px` + `border-radius:11px`
  （半径 = 高度一半 ⇒ 两端半圆）/ `max-width:340px` + `text-overflow:ellipsis`
- DOM 在 `#restart-btn` **之前**（同处 `.bar-right`，DOM 序即视觉序）
- 默认 `display:none`，仅 `status.kind === 'rolled-back'` 时 `data-visible="true"`
- `renderRollbackCapsule(value)` 由 `renderDesktopUpdate` 末尾调用；文案
  「⚠ 已回退：<被撤回版本> → <当前运行版本>」，完整降级原因挂 `title` + `aria-label`
- `role="status" aria-live="polite"`；重新进入 `validating`/`completed` 自动隐藏

数据来源（后端）：`Start-DSH-Portable.ps1` 的 `Save-RecoveredDesktopPointer` 在降级时写
`Set-UpdateState -Phase 'rolled-back'` + 显式 `-TargetVersion`；`src/main.ts` 的
`applyPortableDesktopUpdateState` 映射为 `kind:'rolled-back'`。

### 2. 同批在途改动（用户 2026-10-01 确认一并纳入）

这些不是本次修复产出，是并行会话落在 `assets/**` 的既有改动，此前未登记基线、
阻塞了 UI 快通道。经用户确认（A 路径）一并纳入：

- **统一字体栈**：`theme.css` 新增 `--chrome-font-ui`（Inter → SF Pro Text → 系统 UI →
  PingFang SC / 微软雅黑 / Noto Sans SC），7 个 chrome 页面（shell / settings / about /
  shortcuts / feature-panels / browser-panel / startup）统一改为 `var(--chrome-font-ui)`
- **圆角阶梯**：`--chrome-radius` 8→10px、`--chrome-radius-sm` 6→8px、新增
  `--chrome-radius-inner: 5px`（= 容器 10 − 内边距 5，保证同心）
- **亮色对比度**：`--chrome-surface-3` `#e4e4e7`→`#dcdce0`、`--chrome-text-faint`
  `#71717a`→`#5c5c66`
- **设置入口合并**：`#update-btn`（检查更新）并入 `#settings-btn`（DSH 设置），
  左下角桌面设置入口已移除，顶栏设置成为唯一入口
- **更新指示器重做**：进度环改用 `mask: radial-gradient(...)` 描边，
  `data-indicator` 三态（`none`/`progress`/`spinner`），spinner 为独立旋转动画，
  `prefers-reduced-motion: reduce` 下关闭
