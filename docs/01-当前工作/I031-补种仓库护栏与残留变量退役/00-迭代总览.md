# I031 · 补种仓库护栏：重试不再丢掉已知 store + 退役死变量 `PNPM_STORE_DIR`

> 触发：用户「**能不能不要挤牙膏，你还有很多其他任务做的**」→ 把上一轮自己写成
> 「建议留到下次动 `src/` 时一起做」的两条加固**当场做完**，不再挂在嘴上。
> 性质：**防御性改动**（不改用户可见行为），因此走完整 `src/` 门禁 + A/B 候选暂存。

## 0. 结论

| 项 | 改前 | 改后 |
|---|---|---|
| 首次安装失败后的**重试** | 重试参数写成 `{}` → **丢掉已解析到的 store** → pnpm 改用环境默认仓库 → 与 `node_modules/.modules.yaml` 记录的仓库不一致即抛 `ERR_PNPM_UNEXPECTED_STORE` | 重试**只放宽「离线」，保留 `--store-dir`**（4 处：profile 补种 / 官方运行时补种 / 启动 peer 补齐 / 套件替换） |
| 解析不到仓库的目录 | 静默发出不带 `--store-dir` 的命令 | profile 补种类路径**告警、不静默**；机会性的「构建许可恢复」**直接跳过**（它本就失败只告警） |
| `PNPM_STORE_DIR` | `src/portable-paths.ts` 与 `Portable-Environment.ps1` 各导出一份，**`src/` 无任何读取方、pnpm 也不读** | 两处**退役**；用例改钉「不再导出」 |

升级后的全量门禁：`tsc` 0 · **489 tests / 477 pass / 0 fail / 12 skip** · `ui-baseline` PASS（较上轮 +3 条新用例，**未削弱任何既有断言**）。

## 1. 真因更正（本节比代码重要）

上一轮（I030 §8.1）把 2026-09-14 那次 `ERR_PNPM_UNEXPECTED_STORE` 归因成
「`resolvePnpmStoreDir` 返回 `undefined` → 发出不带仓库的命令」。本轮照着这个假设加"拒绝执行"守卫，
**结果 3 条既有用例当场变红**——反而把真因逼了出来：

- 日志原文是 `currently linked from the store at "G:\.pnpm-store\v11"`：`.modules.yaml` **记录到了**仓库，
  说明**首次尝试确实带了** `--store-dir`；
- 首次失败后进入重试分支，而重试写的是 `buildSeedPluginArgs(..., {})` —— **把仓库丢了**；
- pnpm 于是改用 `PNPM_HOME` 推出的默认仓库（`Data\Development\pnpm-home\store\v11`），
  与记录不一致 → 报错。

⇒ **「重试丢仓库」才是真因**；「解析不到仓库」只是同族风险（且没有记录时 pnpm 无从比对，不会抛该错误）。
据此把实现调整为：**重试保留仓库**（真修复）+ 解析不到时**告警/跳过**（不改变既有语义），
并新增用例把"重试必须保留仓库"钉死。**先写测试让假设翻车，比顺着假设改代码值钱。**

## 2. 改动清单

| 文件 | 改法 | 理由 |
|---|---|---|
| `src/plugin-seed.ts` | 新增 `hasUnresolvedStore()` / `storelessSeedWarning()` | 把「已有依赖但没有仓库记录」变成一个显式、可测的状态，提示文案统一 |
| 同上 | 4 处重试 `{}` → `{ storeDir }`（官方运行时、启动 peer、profile 补种、套件替换） | **真修复**：重试只放宽离线，绝不换仓库 |
| 同上 | `seedCommunityPlugins` / `applyPendingProfileUpdates` / `seedOfficialRuntime` / `ensureOfficialLaunchPeers`：解析不到仓库时 `console.warn` | 不静默（用户报错时能看出是仓库记录的问题） |
| 同上 | `repairIgnoredBundledBuilds`：解析不到仓库时**告警并 return** | 该分支是"机会性构建恢复"，失败本就只告警；此处跳过比发出可疑命令更安全 |
| `src/portable-paths.ts` | 删除 `PNPM_STORE_DIR` 导出 | 死变量：`src/` 无读取方、pnpm 不读（I030 已实测两种配置改法均无效） |
| `Portable-Environment.ps1` | 删除同一变量（**保留 UTF-8 BOM**） | 同上；启动器与构建脚本共用该环境 |
| `test/plugin-seed.test.ts` | +3 用例：重试保留仓库 / 坏记录只跳过 / 护栏不误伤 | 钉住"重试换仓库"这个真因 |
| `test/portable-paths.test.ts` | 原断言 `PNPM_STORE_DIR` 存在 → 改为断言 **`undefined`** | 按 D-27「控件退役要连测试一起退役」，改钉新契约而不是删掉了事 |
