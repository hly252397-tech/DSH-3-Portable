1. P0 数据可靠性：继续 I009 的宿主存储与跨端口迁移；任务 / 知识 / 自动化数据与安装槽分离，保留可验证备份。这是正式功能对齐的发布前置条件。
2. P1 本地工作流：Q02 搜索先行增量；随后 Q05 知识检索、Q06 自动化全流程、Q07 扩展配置与 Q09 工具审查。
3. P2 智能体能力：Q01、Q03、Q04、Q08、Q10，复用运行时公开服务，补可追踪状态与实测。
4. P3 跨设备与语音：Q11、Q12、Q13 剩余项；不自动购买服务、上传资料或开启远程访问。

Inventor 2027 和数据可视化继续保留在 I009，属于本项目业务需求，不能因 Qoder 官网未列出而取消。

## 本轮 Q02 实现边界

新增“搜索任务”入口及工作台页。标题从当前 Session Controller 目录筛选，正文走同版本公开 `sessions.search(query, signal)`，不扫描任意用户文件、不调用模型。支持工作区筛选、去重、取消过时请求、错误重试、上限提示和回到原会话。

本轮不把知识库搜索、会话搜索和项目文件检索混称为已完成的统一全局索引。当前正文 API 只返回会话和摘录，打开的是原会话，尚不保证定位至精确消息行。
