# 外壳重启按钮：重启中图标不再转圈（2026-09-16）

## 原因（用户提出）

重启过程中，外壳顶栏那个电源图标**一直在转圈**。用户要求：**重启时图标不要转圈**。

## 根因（源码为证）

`assets/shell.html` 第 78-80 行：

```css
.nav.restart.spinning{opacity:.6;pointer-events:none}
.nav.restart.spinning img{animation:dsh-restart-spin .7s linear infinite}   /* ← 转圈来源 */
@keyframes dsh-restart-spin{from{transform:rotate(0)}to{transform:rotate(360deg)}}
```

## 改法

把该行的动画去掉，**保留"变暗 + 不可点"**作为"正在重启"的忙碌提示（信息不丢，只是不再旋转）：

```css
.nav.restart.spinning img{animation:none}
```

`@keyframes dsh-restart-spin` 一并保留（已无引用，删除它会扩大改动面；保留零风险）。

## 覆盖面与技术细节

- **为什么改这里而不是插件**：该图标属于**外壳 chrome**（Electron 外层窗口），而本地界面插件运行在 DSH 页面文档里，**跨文档够不到**。所以这一类"外壳自身观感"必须改 `assets/**`。
- **生效路径**：`assets/**` 属于不可变槽素材 → **不能免重启**；且本次 `Build-UI-Only.cmd` 快通道**正确地拒绝**了（`dist/` 因本会话反复跑 tsc 而比已部署 `app.asar` 新），因此走全量构建 → 候选槽 → 用户重启生效。
- **回归面**：仅一处 CSS 声明由 `animation:<name>` 改为 `none`；不含 JS、不含结构、不含其它选择器。`.nav.restart.confirming`（二次确认红态）与 `prefers-reduced-motion` 分支均未触碰。
