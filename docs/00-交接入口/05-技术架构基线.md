# 技术架构基线

更新时间：2026-09-26（Asia/Shanghai）

当前生效的技术硬约束：

- Windows x64、macOS arm64/x64 与 Linux x64，Electron 本地 HTTP 壳。
- 官方 Node 24（实际二进制见 `App/resources/node/node.exe --version`）；DSH 运行时版本以 `package.json` `config.bundledDshVersion` 与 `src/bundled-plugins.ts` `OFFICIAL_DSH_VERSION` 为准（当前 `0.1.7-rc.2`）；打包预装；官方运行时只在关于页手动升级，启动不查版本、不自动升。
- **官方运行时家族钉版靠 `resolutionMode: time-based`，不靠 `overrides`**：pnpm 11.24 完全忽略 `package.json` 的 `pnpm.overrides`，且通配 overrides（`@deepseek-ai/dsh-*`）实测不命中；官方发版包把传递依赖写成 `^<同元组预发布>`，最高版语义会拉出「根包 rc.1 + 传递包 rc.2」的混用家族，被家族对齐门禁判失败。三个入口必须同时写 `time-based`：生成的 `pnpm-workspace.yaml`、安装参数、以及**已存在**的运行时目录（`ensureRuntimeResolutionMode`）。
- 官方包不得写入 Web profile；社区插件只写入用户 profile，禁止复制进 DSH 安装目录 `node_modules`。
- 在线安装继续走 `dsh plugin add`；随包 Node 目录必须带 pnpm。
- DSH 使用 `--port 0 --no-open`，仅监听 `127.0.0.1`，不得再打开系统浏览器。
- 仅加载经校验的 loopback HTTP 地址。
- `nodeIntegration: false`、`contextIsolation: true`。
- 正常退出走受控关闭通道；超时仅按 PID 兜底，不全局结束 `node.exe`。
- 卸载不得按安装目录扫杀进程，必须排除卸载器自身。
- 不记录密钥、授权请求头、会话正文或模型输出。
- macOS 签名与公证凭据为后续正式发布配置；当前测试版允许未签名、未公证发布。
