# 项目概览

更新时间：2026-09-26（Asia/Shanghai）

## 项目定位

本项目为 DeepSeek Harness 提供 Windows x64、macOS Apple Silicon（arm64）、macOS Intel（x64）与 Linux x64 桌面启动器。通过 Electron 管理本地 DSH Web 服务与窗口，使非技术用户无需安装系统 Node 或执行命令行。

## 当前阶段

当前版本以 `package.json` `version` 为准（2026-09-26 读数为 `1.0.76`）。Windows x64、macOS arm64/x64 与 Linux x64 的远端构建、打包和启动冒烟均已通过。

## 核心能力

- 内置 Node 24 运行时（实际版本见 `App/resources/node/node.exe --version`）与固定 DSH 运行闭包。
- 启动 DSH Web UI 并使用随机 loopback 端口。
- 桌面窗口、单实例、托盘、错误提示和受控关闭。
- Windows x64 安装器与 ZIP、macOS arm64/x64 的 DMG 与 ZIP，以及 Linux x64 的 AppImage 与 deb。
- 随包装配功能插件与 dshmarket 插件市场的离线仓库，首次启动写入用户 Web profile。**项数与版本以 `src/bundled-plugins.ts` 的 `BUNDLED_PLUGINS` 为唯一事实源**（2026-09-26 读数：15 项）。
- 随包提供 pnpm，兼容 code-ui 与 dshmarket 的 `dsh plugin add` 在线安装。

## 稳定边界

- 不修改 DSH 上游仓库。
- 不开放局域网访问；服务只监听 `127.0.0.1`。
- 桌面更新默认策略是 `notify`：**启动后延迟 10 秒自动检查一次**（`STARTUP_UPDATE_CHECK_DELAY_MS`），只提示、不自动下载；用户也可从托盘手动检查。策略取值 `notify` / `auto-download` / `manual` 由 `src/desktop-updater.ts` 的 `DEFAULT_UPDATE_PREFERENCES` 与用户偏好共同决定。插件更新继续复用 DSH profile 插件协议。
- 用户数据**不再只落在 `%USERPROFILE%\.dsh`**：便携版按运行时版本绑定**独立家园代际**（当前 `v4-rc2b`），数据在 `Data/DSH-generations/<代>/home`；冻结的 `Data/DSH` 供旧版继续读取。升级和卸载不得删除任一代。
